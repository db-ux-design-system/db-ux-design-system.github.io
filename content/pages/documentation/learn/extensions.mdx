## Core or extension?

The core – Foundation and Components – is the same for every product. Extensions build on it and add standards for a specific domain. You always need the core. You need an extension only if your product works in its domain.

| Extension             | Domain                                       |
| --------------------- | -------------------------------------------- |
| Passenger Information | Information standards for travelers          |
| DataViz               | Data visualization, currently in Beta        |
| Table                 | Display of large data sets                   |
| Content               | Consistent communication – not yet available |

All extensions are presented under <DBLink href="/documentation/extensions" variant="inline">Extensions</DBLink>.

</DBSection>

## Get started with an extension

1. Set up the core first – see [Design](/documentation/get-started?role=design) or [Development](/documentation/get-started?role=development).
2. Read the documentation of the extension in the Marketing Portal.
3. Enable the Figma library of the extension in addition to Core Foundation and Core Components.
4. Add the code of the extension, if it provides any.

</DBSection>
