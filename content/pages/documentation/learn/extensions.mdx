## The core is for everyone, an extension for one domain

The **core** – Foundation and Components – is the same for every product. An **extension** builds on it and adds standards for one domain, so you need it only if your product works in that domain.

<LearnAside>

| Extension             | Domain                                       |
| --------------------- | -------------------------------------------- |
| Passenger Information | Information standards for travelers          |
| DataViz               | Data visualization, currently in Beta        |
| Table                 | Display of large data sets                   |
| Content               | Consistent communication – not yet available |

All extensions are presented under [Extensions](/documentation/extensions).

</LearnAside>

</LearnBlock>

<LearnBlock>

## Each extension brings its own material

An extension can bring a Figma library, code and documentation in the Marketing Portal. The [Extensions overview](/documentation/extensions 'All extensions and their domains.') shows what exists.

<LearnAside>

| Extension             | Design        | Code                                            | Documentation                                                                                                                                                                |
| --------------------- | ------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Passenger Information | Figma library | Web Components in GitLab (login required)       | [Marketing Portal](https://marketingportal.extranet.deutschebahn.com/marketingportal/Design-Anwendungen/User-Experience/DB-UX-Design-System/extensions/reisendeninformation) |
| DataViz               | Figma library | Power BI templates and code snippets for Plotly | [Marketing Portal](https://marketingportal.extranet.deutschebahn.com/marketingportal/Design-Anwendungen/User-Experience/DB-UX-Design-System/extensions/dataviz)              |
| Table                 | –             | –                                               | [Marketing Portal](https://marketingportal.extranet.deutschebahn.com/marketingportal/Design-Anwendungen/User-Experience/DB-UX-Design-System/extensions/table)                |

The Marketing Portal requires a login. Deep links do not work before login – open the link again after signing in.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Start with the core

Set up the core with the [Figma setup](/documentation/learn/figma-setup 'Get access to the Figma libraries.') or your framework package. Then add the library and code of the extension from [Resources](/documentation/resources#extensions 'Links to the extension libraries and packages.').

<LearnAside>

1. Set up the core first – in [Design](/documentation/get-started?role=design) or [Development](/documentation/get-started?role=development)
2. Read the documentation of the extension in the Marketing Portal
3. Enable the Figma library of the extension in addition to Core Foundation and Core Components
4. Add the code of the extension, if it provides any

</LearnAside>

</LearnBlock>
