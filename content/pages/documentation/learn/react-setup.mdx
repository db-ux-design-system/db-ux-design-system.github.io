## You need a React project and Node.js

Any React project works, for example one created with Vite. The commands on this page use pnpm.

<LearnAside>

- **Package manager:** with npm, use `npm i` instead of `pnpm add`.
- **Browsers:** the last three versions of Chrome and Edge, Firefox ESR and the last two major versions of Safari.
- **Versions:** the setup was tested with Vite 8, React 19 and version 6 of the design system packages.
- **DB Theme:** products of Deutsche Bahn also need the DB Theme. You can start without it, because the whitelabel theme works right away.

### Start from an example instead

Instead of an empty project, you can copy the matching example project. It already contains the packages and the styling setup:

```shell
npx degit db-ux-design-system/examples/react-example my-app
cd my-app
npm install
npm run dev
```

The examples use the whitelabel theme and an older version of the design system. Update the packages before you build on an example, and add the [DB Theme](/documentation/learn/db-theme-setup) for a product of Deutsche Bahn. All example projects are listed under [Start from an example project](/documentation/learn/examples).

</LearnAside>

</LearnBlock>

## Install three packages

The React components need both style packages: the component styles and the foundation underneath them.

```shell
pnpm add @db-ux/react-core-components @db-ux/core-components @db-ux/core-foundations
```

<LearnAside>

| Package                        | Contains                                      |
| ------------------------------ | --------------------------------------------- |
| `@db-ux/react-core-components` | The components as React components            |
| `@db-ux/core-components`       | The styles of the components                  |
| `@db-ux/core-foundations`      | Tokens, the whitelabel theme, fonts and icons |

</LearnAside>

</LearnBlock>

<LearnBlock>

## Load the styles in the right order

Import the theme first and the component styles after it. The `@layer` line fixes this order.

```css
/* src/index.css */
@layer whitelabel-theme, db-ux;
@import '@db-ux/core-foundations/build/styles/theme/rollup.css' layer(whitelabel-theme);
@import '@db-ux/core-components/build/styles/bundle.css' layer(db-ux);
```

<LearnAside>

### Use the Vite plugin instead

With Vite, the plugin replaces the two imports:

```shell
pnpm add @db-ux/core-vite-plugin --save-dev
```

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import dbUxPlugin from '@db-ux/core-vite-plugin';

export default defineConfig({
	plugins: [dbUxPlugin()],
});
```

```css
/* src/index.css */
@import '@db-ux/core-vite-plugin/index.css';
```

### Pick the file for your bundler

| File           | Use when                                               |
| -------------- | ------------------------------------------------------ |
| `rollup.css`   | You build with Vite or Rollup                          |
| `webpack.css`  | You build with Webpack or Next.js                      |
| `relative.css` | You copy icons and fonts into your own `public` folder |

</LearnAside>

</LearnBlock>

## Render a button to check the setup

A button with an icon shows in one place whether styles, font and icons load.

```tsx
import { DBButton } from '@db-ux/react-core-components';
<DBButton variant="brand" icon="arrow_right">
	Add item to cart
</DBButton>;
```

<LearnAside>

| Check  | Expected                                                                                       |
| ------ | ---------------------------------------------------------------------------------------------- |
| Styles | The button has a filled background in the brand color and rounded corners.                     |
| Font   | The DevTools show `OpenSans` as the rendered font – or `DB Neo Screen Sans` with the DB Theme. |
| Icon   | An arrow appears in front of the text.                                                         |

</LearnAside>

</LearnBlock>

## Keep the colors intact in the build

Vite 8 minifies CSS with LightningCSS, which breaks the `light-dark()` colors in the production build. Switch the minifier to esbuild.

```ts
// vite.config.ts
export default defineConfig({
	build: { cssMinify: 'esbuild' },
});
```

<LearnAside>

Install esbuild as a dev dependency: `pnpm add esbuild --save-dev`. Other bundlers and older Vite versions do not need this setting.

</LearnAside>

</LearnBlock>

## If something does not look right

Most setup problems come from the order of the styles or from asset paths that do not match your bundler.

<LearnAside>

| Symptom                          | Cause and fix                                                                                                                                        |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Components render without styles | The CSS import is missing, or the theme is loaded after the component styles. Make `@layer whitelabel-theme, db-ux;` the first statement.            |
| Font or icons are missing        | The browser cannot find the asset files. A `.woff2` request fails in the Network tab. Switch between `rollup.css`, `webpack.css` and `relative.css`. |
| Colors break only in the build   | The `cssMinify` setting from the previous step is missing.                                                                                           |

If none of this helps, open an issue in the [core-web repository](https://github.com/db-ux-design-system/core-web/issues/new/choose). Please check first whether the issue already exists.

</LearnAside>

</LearnBlock>

Neither plugin is required to get started. Add them once your first component renders.

### PostCSS plugin

Reduces the bundle size by resolving `var()`, `calc()`, `color-mix()` and `light-dark()` at build time and removing unused declarations.

```shell
pnpm add @db-ux/core-postcss-plugin esbuild --save-dev
```

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import { dbUxFlatten } from '@db-ux/core-postcss-plugin';

export default defineConfig({
	css: {
		// Vite 8+ uses LightningCSS by default and skips PostCSS plugins without this line
		transformer: 'postcss',
		postcss: {
			plugins: [dbUxFlatten()],
		},
	},
	build: {
		// Vite 8+: keeps light-dark() intact in the production build (needs esbuild)
		cssMinify: 'esbuild',
	},
});
```

### ESLint plugin

Reports incorrect component usage directly in the editor.

```shell
pnpm add eslint @db-ux/core-eslint-plugin @typescript-eslint/parser --save-dev
```
