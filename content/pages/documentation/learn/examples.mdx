## Try it in the browser first

Three React demos run in **StackBlitz** without any local setup. The editor opens in a new tab and starts the app.

<LearnAside>

| Example       | Shows                                                  | Open                                                                                            |
| ------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| Documentation | An application shell with navigation and content pages | [StackBlitz](https://stackblitz.com/edit/db-ux-design-system-examples-tue2w1lm?file=index.html) |
| Table         | A data table inside an application shell               | [StackBlitz](https://stackblitz.com/edit/db-ux-design-system-examples-7yy1wm69?file=index.html) |
| KPI           | A dashboard with KPI cards                             | [StackBlitz](https://stackblitz.com/edit/db-ux-design-system-examples-8qc2ure1?file=index.html) |

## Copy only the example you need

**degit** copies one folder of the repository without its Git history. Replace `react-example` with the folder of your example.

```shell
npx degit db-ux-design-system/examples/react-example my-app
cd my-app
npm install
npm run dev
```

<LearnAside>

### Clone the whole repository instead

If you want all examples at once, clone the repository and change into one folder:

```shell
git clone https://github.com/db-ux-design-system/examples.git
cd examples/react-example
npm install
npm run dev
```

### Python example

The Python example lives in a subfolder: `db-ux-design-system/examples/python/htmx-jinja-example`. Instead of the npm commands, it needs `pip install -r requirements.txt` and starts with `python app.py`.

</LearnAside>

## Update before you build on it

The examples use the **whitelabel theme** and older versions. Update them and add the [DB Theme](/documentation/learn/db-theme-setup 'Colors, fonts and icons of the brand.') for a product.

<LearnAside>

Without the DB Theme, the examples show the whitelabel defaults instead of the DB font and icons.

To update the design system packages of the React example to the latest version:

```shell
npm install @db-ux/react-core-components@latest @db-ux/core-components@latest @db-ux/core-foundations@latest
```

Use the matching package for other frameworks, for example `@db-ux/ngx-core-components` or `@db-ux/v-core-components`. Check the [Release Notes](/documentation/releases/release-notes) for Breaking Changes when the update crosses a Major version.

</LearnAside>

</LearnBlock>

## Report an example that does not work

Open an issue in the [examples repository](https://github.com/db-ux-design-system/examples/issues 'Report a problem with one of the example projects.'). Please check first whether the issue already exists.

<LearnAside>

Problems with a component itself, not with the example, belong in the [core-web repository](https://github.com/db-ux-design-system/core-web/issues/new/choose).

</LearnAside>
