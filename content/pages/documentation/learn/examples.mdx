## Example projects per framework

Each project shows a minimal, working setup for one framework. The README of each project lists every step that was needed to create it – useful if you want to reproduce the setup in your own project.

| Framework           | Project                                                                                                      | Built with                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------- |
| React               | [react-example](https://github.com/db-ux-design-system/examples/tree/main/react-example)                     | Vite, Sass                    |
| React with Tailwind | [react-tailwind-template](https://github.com/db-ux-design-system/examples/tree/main/react-tailwind-template) | Vite, Tailwind, Vite plugin   |
| Angular             | [angular-example](https://github.com/db-ux-design-system/examples/tree/main/angular-example)                 | Angular CLI, SCSS             |
| Vue                 | [vue-example](https://github.com/db-ux-design-system/examples/tree/main/vue-example)                         | Vite, Sass                    |
| Python with htmx    | [htmx-jinja-example](https://github.com/db-ux-design-system/examples/tree/main/python/htmx-jinja-example)    | Flask, Jinja2, Web Components |
| Custom theme        | [custom-theme-example](https://github.com/db-ux-design-system/examples/tree/main/custom-theme-example)       | React, own icon font          |

### Run an example locally

```shell
git clone https://github.com/db-ux-design-system/examples.git
cd examples/react-example
npm install
npm run dev
```

Replace `react-example` with the folder of the example you want to run. The Python example additionally needs `pip install -r requirements.txt` and starts with `python app.py`.

## Before you build on an example

<DBNotification
