## There is no Backdrop component

The **Drawer** brings its own backdrop. For your own overlays, apply the same color with two tokens: the strongest text color and an opacity.

<LearnAside>

The backdrop uses `--db-adaptive-on-bg-basic-emphasis-100-default` as color and `--db-opacity-lg` as opacity. Both adapt to Light Mode and Dark Mode.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Use the tokens in CSS

Mix the color with the opacity using relative color syntax, either on your own element or on `::backdrop` of a dialog.

```css
.my-backdrop,
dialog::backdrop {
	background-color: color(
		from var(--db-adaptive-on-bg-basic-emphasis-100-default) srgb r g b / var(--db-opacity-lg)
	);
}
```

<LearnAside>

For a weaker backdrop, like the `weak` variant of the Drawer, use `--db-opacity-sm` instead of `--db-opacity-lg`.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Use the tokens in SCSS

With Sass, take the same tokens from the foundation package.

```scss
@use '@db-ux/core-foundations/build/styles/colors';
@use '@db-ux/core-foundations/build/styles/variables';

.my-backdrop,
dialog::backdrop {
	background-color: color(
		from #{colors.$db-adaptive-on-bg-basic-emphasis-100-default} srgb r g b /
			#{variables.$db-opacity-lg}
	);
}
```

<LearnAside>

The weaker variant uses `variables.$db-opacity-sm`.

</LearnAside>

</LearnBlock>
