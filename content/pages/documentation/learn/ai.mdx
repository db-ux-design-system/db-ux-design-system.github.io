## Without context, agents guess

AI coding agents know common libraries, but not the exact API of the DB UX Design System. Without context, they invent component names, properties and token values that look right but do not exist.

<LearnAside>

The tools in this article give agents the real source instead: the generated code and documentation shipped in the `@db-ux` packages. Generated code still needs your review – the tools reduce guessing, they do not replace your own judgment.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Three tools, each for one job

The **MCP Server** answers agent requests live, the **Agent CLI** writes project rules into your repository, and **Code Connect** shows code for Figma designs. The MCP Server and the Agent CLI complement each other, so use both if you can.

<LearnAside>

| Tool                | What it does                                                                                            | Use it when                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `@db-ux/mcp-server` | Answers agent requests live: component APIs, code examples, tokens, icons, migration and review prompts | Your IDE supports the Model Context Protocol  |
| `@db-ux/agent-cli`  | Writes the documentation of your installed `@db-ux` packages into `.github/copilot-instructions.md`     | You want project rules that every agent reads |
| Code Connect        | Shows the matching code snippet for a Figma design in Dev Mode                                          | You implement designs from Figma              |

The Model Context Protocol (MCP) is an open standard that lets an IDE connect agents to external tools and data sources.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Start with the Agent CLI

Generate the project rules with `npx @db-ux/agent-cli`, then register the [MCP Server](/documentation/learn/mcp-server 'Configuration for each IDE and the connection check.') in your IDE.

<LearnAside>

```shell
npx @db-ux/agent-cli
```

1. Run `npx @db-ux/agent-cli` in the root of your repository. It creates or updates `.github/copilot-instructions.md` for the `@db-ux` packages installed in your project.
2. Add the `db-ux` entry to the MCP configuration of your IDE.
3. Ask your agent to list the components of the design system. It should answer with the real component names.

Run the Agent CLI again after every update of the design system. Monorepos, version pinning and IDE-specific details are covered in the MCP Server article.

</LearnAside>

</LearnBlock>

## Ask for the task, not for the code

Describe what you want to build, migrate or check. The MCP Server offers prompts for these tasks, and the agent calls the matching tools on its own.

<LearnAside>

| Task                      | Prompt or tool of the MCP Server                   | Example request                                                     |
| ------------------------- | -------------------------------------------------- | ------------------------------------------------------------------- |
| Build a page or component | `scaffold_page`                                    | "Build a booking form in React with DB UX components."              |
| Migrate from DB UI        | `scan_generation_2_migration`, `migrate_component` | "Scan this file for Generation 2 patterns and migrate it to Vue."   |
| Review code               | `review_ui_code`                                   | "Review this component for DB UX compliance."                       |
| Check accessibility       | `audit_accessibility`                              | "Audit this dialog against WCAG 2.2 AA and list manual test steps." |

WCAG 2.2 AA is the accessibility level the audit checks against. An automated audit does not replace manual testing with assistive technologies.

The [migration from DB UI](/documentation/learn/migration) describes how an agent can do the groundwork of a migration.

</LearnAside>

</LearnBlock>
