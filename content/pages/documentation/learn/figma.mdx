### Property Icons

Component properties in the Figma library use emoji prefixes to indicate their type and purpose at a glance.

| Icon | Purpose | Example |
|------|---------|---------|

| 📦 | Slot (content area) | `📦 Children` |
| 🔄 | Icon swap (instance swap for icons) | `🔄 Icon` |
| ✏️ | Text override | `✏️ Label` |

### Button
#### Multi-line text within Full Width Buttons

<DBNotification variant="standalone" semantic="informational">
Only use multi-line text in exceptional cases, such as when the text is extended due to translation.
</DBNotification>

### ControlPanel & Shell

#### Popover Navigation Horizontal: Overflow Buttons

<DBNotification variant="standalone" semantic="informational">
Desktop only – Mobile Popover Horizontal is limited to SubNavigation (Level 2) with a single level and does not display overflow buttons, an Active Indicator, or expanded Popover items.
</DBNotification>

The **Clip Content** setting required for correct horizontal overflow removes all elements outside the children container of Popover Navigation – including expanded Popover items and the Active Indicator (Level 1). Show either the overflow cropping or the expanded/active state, not both at the same time.

#### Scroll behavior of vertical navigation and Meta

In the vertical navigation, the Meta navigation docks to the bottom edge. This applies to the Drill Down and Tree variants.

When many navigation items fill the available space, they run underneath the Meta navigation instead of pushing it away. In Figma, change the auto layout behavior of the navigation from Fill to Hug so the Meta navigation stays below all navigation items and is pushed out of the visible area by the navigation.
