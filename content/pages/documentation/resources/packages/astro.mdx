## When to use this package

[Astro](https://astro.build/) is a framework for fast, content-driven websites. The integration connects it with the React components of the design system and handles the setup for you.

{/* prettier-ignore */}
<DBNotification variant="standalone" semantic="warning" headline="Early version">
	`@db-ux/astro` is at version 0.1.0. It expects `@db-ux/core-components` 4.x and Astro 5 as peer dependencies – both are behind the current versions. Check the <DBLink href="https://github.com/db-ux-design-system/astro" variant="inline">repository</DBLink> for the current state before you start a new project with it. For an up-to-date setup, follow the <DBLink href="/documentation/resources/packages/react" variant="inline">React guide</DBLink> instead.
</DBNotification>

## Install

### 1. Create an Astro project

```shell
npm create astro@latest
```

Choose `Use minimal (empty) template` in the questionnaire. The integration is designed for an empty project.

### 2. Install the integration

```shell
npm i
npm create @db-ux/astro
```

The installer detects your package manager, checks that you are in an Astro project and installs `@db-ux/astro` together with all required peer dependencies.

</DBSection>

<DBSection spacing="small" width="auto">

## Setup

Add the integration to `astro.config.mjs`:

```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import { dbUxAstro } from '@db-ux/astro';

export default defineConfig({
	integrations: [
		dbUxAstro({
			appName: 'My app',
		}),
	],
});
```

## Troubleshooting

| Symptom                                             | Cause and fix                                                                                                            |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| The installer reports that this is no Astro project | Run it in the root of your Astro project, where `astro.config.mjs` is located.                                           |
| `npm create db-ux-astro` fails                      | The package name is `@db-ux/create-astro`. Use `npm create @db-ux/astro`.                                                |
| Peer dependency conflicts on install                | The integration expects Core 4.x and Astro 5. Newer versions of either cause conflicts until the integration is updated. |

If none of this helps, open an issue in the [astro repository](https://github.com/db-ux-design-system/astro/issues). Please check first whether the issue already exists.
