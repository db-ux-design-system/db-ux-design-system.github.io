### Navigation Structure

On mobile, the Sub Navigation only supports a single flat level. If the Sub Navigation has more than one level on desktop, the navigation is restructured for mobile.

<div className="guideline-examples">
	<GuidelineExample

### Control Panel and Sub Navigation

The following table shows which combinations of Control Panel positions, Control Panel Navigation (Drawer) variants, and Sub Navigation positions are supported.

| Control Panel | Control Panel Position | Control Panel Navigation (Drawer) | Sub Navigation Position |
| ------------- | ---------------------- | --------------------------------- | ----------------------- |
| Mobile        | Top                    | Drill Down                | ❌                      |
| Mobile        | Top                    | Drill Down                | Top (1 Level)           |
| Mobile        | Top                    | Drill Down                | Bottom (1 Level)        |
| Mobile        | Top                    | Tree                      | ❌                      |
| Mobile        | Top                    | Tree                      | Top (1 Level)           |
| Mobile        | Top                    | Tree                      | Bottom (1 Level)        |
| Mobile        | Bottom                 | Drill Down                | ❌                      |
| Mobile        | Bottom                 | Drill Down                | Top (1 Level)           |
| Mobile        | Bottom                 | Drill Down                | Bottom (1 Level)        |
| Mobile        | Bottom                 | Tree                      | ❌                      |
| Mobile        | Bottom                 | Tree                      | Top (1 Level)           |
| Mobile        | Bottom                 | Tree                      | Bottom (1 Level)        |
| Flat Icon     | Bottom                 | ❌                        | ❌                      |
| Flat Icon     | Bottom                 | ❌                        | Top (1 Level)           |

</DBSection>

### Desktop and Mobile Differences

Shell Mobile and Shell Desktop can be built differently. The navigation structure does not have to be identical on both devices, it can be adapted per device.
