### Control Panel Position

The number of top-level Navigation Items determines the Control Panel position. From four items onwards, Left gives them a persistent vertical overview.

### Sub Navigation Position

The number of sub-level Navigation Items determines the Sub Navigation position. From six items onwards, Left keeps them permanently in view.

### Control Panel and Sub Navigation

The following table shows which combinations of Control Panel and Sub Navigation positions and navigation variants are supported.

| Control Panel | Control Panel Position | Control Panel Navigation | Sub Navigation Position | Sub Navigation Variant |
| ------------- | ---------------------- | ------------------------ | ----------------------- | ----------------------- |
| Desktop       | Top                    | Popover                  | ❌                      | ❌                     |
| Desktop       | Top                    | Popover                  | Top                     | Popover                |
| Desktop       | Top                    | Popover                  | Left                    | Drill Down             |
| Desktop       | Top                    | Popover                  | Left                    | Tree                   |
| Desktop       | Left                   | Drill Down               | ❌                      | ❌                     |
| Desktop       | Left                   | Tree                     | ❌                      | ❌                     |
| Desktop       | Left                   | Drill Down               | Top                     | Popover                |
| Desktop       | Left                   | Tree                     | Top                     | Popover                |
| Flat Icon     | Left                   | ❌                       | ❌                      | ❌                     |
| Flat Icon     | Left                   | ❌                       | Top                     | Popover                |
