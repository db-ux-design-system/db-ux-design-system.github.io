## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Control Panel Position

Choose the Control Panel position based on navigation complexity. Top works for simple apps; Left suits applications with many Navigation Items or deep structures.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=1-1132&embed-host=share"
		description="Use the Top position for applications with few top-level Navigation Items."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=1-1133&embed-host=share"
		description="The Left position with only 2–3 Navigation Items takes up space without adding structural benefit. Consider Top instead."
	/>
</div>

### Sub Navigation Placement

Choose a Sub Navigation position that fits your information architecture and keep it consistent across all pages of your application.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=3-1110&embed-host=share"
		description="Use Sub Navigation Left for pages with many sub-level Navigation Items that benefit from a persistent vertical overview."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=3-1112&embed-host=share"
		description="Do not switch Sub Navigation position when navigating between top-level sections. Users expect the navigation layout to stay stable."
	/>
</div>

</CollapsibleWrapper>

### Navigation Depth

Shell Desktop supports combining Control Panel Navigation and Sub Navigation in various ways. Both can have multiple levels independently. You can mirror the same structure in both, show only a subset, or distribute pages across the two navigation areas.
