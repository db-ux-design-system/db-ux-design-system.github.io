- Use Fixed to keep the Start Slot and End Slot visible while scrolling
- Use Auto to scroll the entire area including the slots

## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Scroll Behavior

Fixed keeps the Start Slot and End Slot visible while scrolling. Auto scrolls the entire area including the slots.

<div className="guideline-examples">
	<GuidelineExample

		description="Use Fixed when the Start Slot or End Slot should stay visible while scrolling."
	/>
	<GuidelineExample
		fullWidth
		variant="dont"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4079-4&embed-host=share"
		description="Don't use Auto when the Start Slot or End Slot should stay visible. They scroll out of the viewport along with the rest of the area."
	/>
</div>

### Main Content Placement

The main content belongs in Children. With Fixed, content in the Start Slot and End Slot stays in place instead of scrolling along.

<div className="guideline-examples">
	<GuidelineExample
		fullWidth
		variant="do"

		description="Place the main content in Children."
	/>
	<GuidelineExample
		fullWidth
		variant="dont"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4079-7&embed-host=share"
		description="Don't place the main content in the Start Slot or End Slot. With Fixed it stays in place there instead of scrolling along."
	/>
</div>

### Slot Size in Fixed

In Fixed, the Start Slot and End Slot permanently take up space and reduce the scrollable area for Children.

	<GuidelineExample
