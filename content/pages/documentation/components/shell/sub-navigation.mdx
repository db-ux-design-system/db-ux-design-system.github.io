## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Mobile Navigation Depth

On mobile, the Sub Navigation supports a single flat level of Navigation Items. Navigation Item Groups cannot be used there.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4049-3&embed-host=share"
		description="On mobile, use a flat level of Navigation Items."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4049-4&embed-host=share"
		description="Don't use Navigation Item Groups on mobile. They cannot be used there."
	/>
</div>

### Items on Mobile

The mobile Sub Navigation shows its Navigation Items in a scrollable row. The more items it contains, the fewer of them are visible at once.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4093-8&embed-host=share"
		description="Use no more than five Navigation Items in the mobile Sub Navigation."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4093-11&embed-host=share"
		description="With more than five Navigation Items, the overview is lost while scrolling. Reduce the number or distribute the destinations differently."
	/>
</div>

### Collapsible Left Navigation

On desktop, users can collapse Sub Navigation Left; it always starts expanded. In the collapsed state, only the button to expand it remains visible.
