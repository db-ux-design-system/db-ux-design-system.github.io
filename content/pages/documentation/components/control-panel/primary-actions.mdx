## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Action Type

Primary Actions hold global actions that are relevant regardless of the current page, such as a search.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4338-6&embed-host=share"
		description="Only use global actions such as search that are relevant regardless of the current page."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4338-8&embed-host=share"
		description="Don't place content-specific actions in Primary Actions. They belong at page level."
	/>
</div>

### Count

Primary Actions work through their priority. The more actions sit there, the less a single one stands out.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4338-2&embed-host=share"
		description="Place at most two actions in Primary Actions."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4338-4&embed-host=share"
		description="More than two actions dilute the priority. Move supporting actions to the Secondary Actions."
	/>
</div>

### Flat Icon Limitation

The Flat Icon variant has no area for Primary Actions.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4338-10&embed-host=share"
		description="Choose a variant with an area for Primary Actions when you need global actions."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4338-12&embed-host=share"
		description="Don't use Flat Icon when Primary Actions are needed. The variant has no area for them."
	/>
</div>

</CollapsibleWrapper>

## Examples

### Split on Desktop and Mobile

On desktop, Primary and Secondary Actions are visible at the same time. On mobile the Drawer separates them: Primary Actions sit on the first level, Secondary Actions inside it. Which actions sit where can differ per device.

<div className="guideline-examples">
	<GuidelineExample
		fullWidth
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4812-1247&embed-host=share"
		description="On desktop, Primary and Secondary Actions sit next to each other and are visible at the same time."
	/>
	<GuidelineExample
		fullWidth
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4814-1263&embed-host=share"
		description="On mobile, put the frequently used action into the Primary Actions so it stays reachable without opening the Drawer."
	/>
</div>
