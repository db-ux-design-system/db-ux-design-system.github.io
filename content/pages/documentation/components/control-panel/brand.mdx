## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### End Slot

All variants except Short have an End slot. It is intended for environment information.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4185-10&embed-host=share"
		description="Only place environment information in the End slot."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4185-12&embed-host=share"
		description="Don't place an application name or interactive elements in the End slot. Actions belong in Control Panel Actions."
	/>
</div>

### Text Hierarchy

By default, both text parts are Regular. If the text shows a hierarchy, only the first part is set to bold.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4782-8&embed-host=share"
		description="For a desired hierarchy, set only the first text part to bold."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4782-18&embed-host=share"
		description="Don't set the second text part to bold, and don't set both. Bold on the second part inverts the hierarchy, bold on both cancels it."
	/>
</div>

The Short variant shows the default logo. It appears in the collapsed Left variants and with Control Panel Bottom.

	<GuidelineExample
		variant="dont"
