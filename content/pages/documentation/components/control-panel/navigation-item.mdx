## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Icon Consistency per Level

Tree Navigation Items allow overriding the default tree-line marker with a custom icon (Navigation Items only – Navigation Item Groups always keep the expand/collapse chevron). Keep icons consistent within a level: either all sibling Navigation Items on a level get a custom icon or none. Levels may differ from each other.

### Slots

Slot availability varies by variant. The Floating Container (for tooltips, popovers, badges) is available on all Navigation Item variants. The End Slot for inline content is only available on vertical Popover and Tree Navigation Items. Flat Icon Navigation Items and horizontal Popover Navigation Items have no content slots.

## Accessibility

### Flat Icon Tooltip

Flat Icon Navigation Items display a tooltip on hover that matches the Text Screenreader value. This ensures consistency between the visual tooltip and what assistive technologies announce. Provide a clear, descriptive text for each Flat Icon Navigation Item – it serves as both tooltip and accessible label. Do not leave it empty or use a different text than the tooltip.
