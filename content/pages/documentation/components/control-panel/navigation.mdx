## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Navigation Destinations Only

The navigation only holds navigation destinations. Actions belong in Primary Actions or Secondary Actions.

<div className="guideline-examples">
	<GuidelineExample
		fullWidth
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4798-2&embed-host=share"
		description="Only use Navigation Items for navigation destinations."
	/>
	<GuidelineExample
		fullWidth
		variant="dont"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4798-6&embed-host=share"
		description="Don't place actions such as search as a Navigation Item. A Navigation Item announces a page change, an action triggers something."
	/>
</div>

### Drill Down for Many Entries

The number of Navigation Items per level decides between Drill Down and Tree. Drill Down shows one level at a time and therefore stays clear even with many entries.

<div className="guideline-examples">
	<GuidelineExample
		fullWidth
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4390-10&embed-host=share"
		description="Use Drill Down from eight Navigation Items per level onwards."
	/>
	<GuidelineExample
		fullWidth
		variant="caution"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4390-12&embed-host=share"
		description="With few entries per level, Drill Down still shows only one level: the overview of the hierarchy is missing even though there is space for it. Consider Tree in that case."
	/>
</div>

### Tree for Few Entries

Tree keeps the full hierarchy visible. Up to seven Navigation Items per level, it stays manageable.

<div className="guideline-examples">
	<GuidelineExample
		fullWidth
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4390-6&embed-host=share"
		description="Use Tree for up to seven Navigation Items per level."
	/>
	<GuidelineExample
		fullWidth
		variant="caution"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4390-8&embed-host=share"
		description="Above seven entries per level, Tree loses its advantage of keeping the full hierarchy visible."
	/>
</div>
