## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Flat Icon Usage

Flat Icon presents all destinations with the same weight. The variant is therefore only suited to equally weighted destinations at the top level.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4799-40&embed-host=share"
		description="Use Flat Icon for equally weighted destinations at the top level."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4799-44&embed-host=share"
		description="Don't use Flat Icon when one destination sits above the others. Otherwise sub-destinations appear next to their parent as equals, and the structure is no longer recognizable."
	/>
</div>

### Items in Flat Icon

Flat Icon is designed for quick access. On desktop, the variant holds no more than ten Navigation Items, ideally seven.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		imageRatio="portrait"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4390-14&embed-host=share"
		description="In Flat Icon on desktop, use at most ten Navigation Items, ideally up to seven."
	/>
	<GuidelineExample
		variant="caution"
		imageRatio="portrait"
		figmaUrl="https://embed.figma.com/design/pElrqVUyojrzYzSagyJPS6/Doku--ControlPanel?node-id=4390-16&embed-host=share"
		description="Longer icon lists work against the quick access Flat Icon is meant for. Reduce the number of destinations."
	/>
</div>
