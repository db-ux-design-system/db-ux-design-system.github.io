## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Usage

The breadcrumb popover item is placed manually and does not appear automatically like the `maxItems` truncation. It keeps the length of the path constant because the collapsed levels stay inside the popover.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/o2INCfqNJAbAIvNuHwgxsg/Doku--Breadcrumb?node-id=4009-25&embed-host=share"
		description="Place the popover item manually to save space on narrow screens while intermediate levels stay reachable."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/o2INCfqNJAbAIvNuHwgxsg/Doku--Breadcrumb?node-id=4009-26&embed-host=share"
		description="Don't use the automatic maxItems truncation when the path is too long for a narrow screen. Its expanded items push the breadcrumb beyond the viewport."
	/>
</div>

### No Mixing

Both mechanisms collapse the same path, but in different ways. Used together, the behavior becomes unpredictable.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/o2INCfqNJAbAIvNuHwgxsg/Doku--Breadcrumb?node-id=4017-44&embed-host=share"
		description="Decide on one truncation approach per breadcrumb, either the popover item or maxItems."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/o2INCfqNJAbAIvNuHwgxsg/Doku--Breadcrumb?node-id=4017-46&embed-host=share"
		description="Don't combine the popover item with the maxItems truncation in the same breadcrumb. Two mechanisms for collapsing the same path make the behavior unpredictable."
	/>
</div>

### Path Anchors

The first item and the current page bound the path and carry the orientation. Only the levels in between are dispensable.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/o2INCfqNJAbAIvNuHwgxsg/Doku--Breadcrumb?node-id=4017-45&embed-host=share"
		description="Keep the first item and the current page visible, and collapse only the levels in between into the popover."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/o2INCfqNJAbAIvNuHwgxsg/Doku--Breadcrumb?node-id=4017-47&embed-host=share"
		description="Don't move the first item or the current page into the popover. Hiding the anchors removes the user's orientation."
	/>
</div>
