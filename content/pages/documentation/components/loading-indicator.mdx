## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### System Processes Only

The Loading Indicator shows how far the system has progressed with a process. Progress that people create themselves, such as completed form steps or finished tasks, is not part of that.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=1-1132&embed-host=share"
		description="Use the Loading Indicator for processes the system runs."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=1-1133&embed-host=share"
		description="Don't show progress that people create themselves with the Loading Indicator. It announces a system result that never arrives in this case."
	/>
</div>

### Indicator Placement

The Loading Indicator sits where the process is triggered or where its result appears. Elements that only wait for the process are disabled.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-2&embed-host=share"
		description="Show the indicator where the process is triggered or where its result appears, and disable the waiting elements."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-3&embed-host=share"
		description="Don't show the indicator on an element that only waits for the process. It then looks as if it were loading itself, and the affected area stays unmarked."
	/>
</div>

### Measurable Progress

If a process's progress can be calculated, the determinate variant shows it as a value in `progressText`. The indeterminate variant is reserved for processes whose progress cannot be calculated.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-5&embed-host=share"
		description="Choose the determinate variant as soon as progress can be calculated, and show the value in progressText."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-6&embed-host=share"
		description="Don't choose indeterminate when progress can be calculated. People then cannot estimate the remaining effort even though the information exists."
	/>
</div>

### Representations per Process

A process can carry two representations when they say different things, such as the running action in the triggering element and its progress in the determinate variant.

	<GuidelineExample

		description="Show two representations only when each carries its own statement: the running action in the triggering element and the progress in the determinate variant."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4125-9162&embed-host=share"

### Process in the Label

The `label` names the process with a verb, not just the object involved.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-8&embed-host=share"
		description="Name the process in the label with a verb."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-9&embed-host=share"
		description="Don't put only the object involved in the label. Without a verb it remains unclear whether the process is running or finished."
	/>
</div>

### Label per State

The `label` follows the state: with `state` set to `active` it describes the running process, with `successful` the result.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-11&embed-host=share"
		description="In the label, describe the running process for active and the result for successful."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/bHzo18blEeRJQGWXvmavvC/Doku--Loading-Indicator?node-id=4005-12&embed-host=share"
		description="Don't keep describing the process in the label after it has finished. Text and status icon then contradict each other."
	/>
</div>

### Hiding the Label

The `label` can be hidden via `showLabel`. The surrounding context then carries the information about which process is meant.

	/>
