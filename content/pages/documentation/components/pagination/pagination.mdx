## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### No Step Sequences

Pagination allows free jumps between all pages. Flows that are completed in a fixed order contradict this principle.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=1-1132&embed-host=share"
		description="Use Pagination for data sets whose pages can be reached in any order."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=1-1133&embed-host=share"
		description="Don't use Pagination for step sequences that are completed in a fixed order. Pagination invites people to skip steps."
	/>
</div>

### First and Last Page

The first and last page should always be visible. They show how large the data set is and where its boundaries are. `boundaryCount` has to be at least `1` for that.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-5&embed-host=share"
		description="Set boundaryCount to at least 1 so that the first and last page appear as a page number in every configuration."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-6&embed-host=share"
		description="Don't set boundaryCount to 0. A truncation then stands at the edges instead of the first and last page, and the size of the data set is not recognizable."
	/>
</div>

### Single-Line Pagination

Pagination should stay on one line. `boundaryCount` and `siblingCount` determine how many page numbers appear; at most seven is the recommended maximum.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-8&embed-host=share"
		description="Choose boundaryCount and siblingCount so that Pagination stays on one line. At most seven page numbers is the recommended maximum."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-9&embed-host=share"
		description="If Pagination wraps into a second line, it becomes harder to operate. Reduce siblingCount or boundaryCount, the latter not below 1."
	/>
</div>

### Truncation per Gap

Every gap in the page sequence is shown by a truncation. It makes visible that further pages lie between two page numbers.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-11&embed-host=share"
		description="Show a truncation for every gap in the page sequence."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-12&embed-host=share"
		description="Don't leave out the truncation. Without it the two page numbers read as consecutive."
	/>
</div>

### Current Page

The marked page is the page whose content is currently shown. It locates people within the data set.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-14&embed-host=share"
		description="Mark the page whose content is shown as the current page."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=4004-15&embed-host=share"
		description="Don't mark a page other than the one shown. A wrong marking looks correct and is not noticeable on the Pagination itself."
	/>
</div>

### Position of the Current Page

Where the current page sits in the data set determines how the row looks and which arrows are operable.

<div className="guideline-examples">

### Collapsing on Narrow Viewports

Below the `sm` breakpoint the page list collapses. The same configuration appears shorter there without any property changing.
