## Guidelines

<CollapsibleWrapper collapsedHeight="320px">

### Title

The title automatically becomes the accessible name of the dialog. It can be set through `text` or placed as content in children.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-44&embed-host=share"
		description="Always provide a title, either through `text` or as content in children."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-46&embed-host=share"
		description="Don't leave the dialog header without a title. The dialog then stays unnamed because the link points to nothing."
	/>
</div>

### Title Wording

The title names the action carried out in the dialog and stays close to the label of the element that opened it. It does not have to match word for word.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-49&embed-host=share"
		description="Name the same task in the title as the triggering element, in wording that matches it."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-51&embed-host=share"
		description="If the title names a different task than the triggering element, it stays unclear whether the expected dialog opened. The title and the label may differ in wording as long as they mean the same task."
	/>
</div>

### Supporting Description

A short description can sit next to the title. It is only needed when the purpose of the dialog does not come across from the title alone.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-54&embed-host=share"
		description="Add a description when the purpose of the dialog does not come across from the title."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-56&embed-host=share"
		description="A description that repeats the title lengthens the way to the content. Leave it out in that case."
	/>
</div>

### Hierarchy in the Header

The title is set in bold by default. Additional content sits below it in regular weight and can optionally be de-emphasized further through size and color.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4209-42257&embed-host=share"
		description="Keep the title in bold and set additional content in regular weight, no larger than the title."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4209-42331&embed-host=share"
		description="Don't set additional content in bold or larger than the title. It then competes with the title and weakens it as the entry point into the dialog."
	/>
</div>

### Start and End Slot

The start and end slot hold additional elements next to the title, such as a badge or an icon. Both are hidden by default.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-59&embed-host=share"
		description="Only place elements in the start and end slot that relate to the content of the dialog."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=4004-61&embed-host=share"
		description="Actions unrelated to the dialog distract from the task. Place them outside the dialog."
	/>
</div>
