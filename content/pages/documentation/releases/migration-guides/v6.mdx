### Refactoring

The following refactoring requires special attention. Existing instances must be reviewed after updating.

#### Heading

- **Alignment property removed:** The alignment is no longer a component property. Any alignment other than "Left" is set directly on the layer inside the component – on the "Heading" text layer (Default Heading) or on the "Container" auto layout (Custom Heading). Instances that were not left-aligned are no longer correctly linked and must be corrected after updating (see <a href="/documentation/learn/figma#setting-the-alignment">Figma Learn</a>).
- **Size property replaced by Visual Size:** The "Size" property has been replaced by "Visual Size". Visual Size sets the visual size independently of the semantic level. Instances that used one of the removed sizes are no longer correctly linked and must be corrected after updating.

The previous Size values map onto Visual Size as follows:

| Size  | Visual Size      |
| ----- | ---------------- |
| `3xl` | removed – use H1 |
| `2xl` | removed – use H1 |
| `xl`  | H1               |
| `lg`  | H2               |
| `md`  | H3               |
| `sm`  | H4               |
| `xs`  | H5               |
| `2xs` | H6               |
| `3xs` | removed – use H6 |

Text content is not overwritten by the update.

<YourAction
	actions={[
		'Review all Heading and Custom Heading instances with an alignment other than "Left" or one of the removed sizes.',
		'Set the alignment on the text layer (Default Heading) or the Container auto layout (Custom Heading) after updating.',
		'Set the corresponding Visual Size according to the mapping above.',
		'Set Visual Size H1 for instances that used 3xl or 2xl, and H6 for 3xs – these sizes have been removed.',
	]}

#### Drawer

- **Children Slot replaces the Drawer Header text layer:** The heading text of the Drawer Header now sits in a Children Slot, consistent with the Dialog Header and the development implementation. Existing heading content is reset after updating and must be re-entered into the text layer inside the slot.
