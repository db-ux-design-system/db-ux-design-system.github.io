## When to use this package

Use Core Foundation on its own only if you need the tokens without any component styles – for example when you build your own components on top of the design system, or when you only need icons and fonts.

<DBNotification variant="standalone" semantic="informational" headline="Looking for components?">
	In most cases{' '}
	<DBLink href="/documentation/get-started/development/packages/core-components" variant="inline">
		Core Components
	</DBLink>{' '}
	is the better choice. It already includes this package.
</DBNotification>

Supported formats: CSS, SCSS and Tailwind.

</DBSection>

<DBSection spacing="small" width="auto">

## Before you begin

You need:

- A project in which you build your own components or only need tokens, icons and fonts.
- Node.js and a package manager. The commands on this page use pnpm. With npm, use `npm i` instead of `pnpm add`.
- A supported browser: the last three versions of Chrome and Edge, Firefox ESR and the last two major versions of Safari.

For products of Deutsche Bahn, you also need access to the Marketing Portal for the [DB Theme](/documentation/get-started/development/packages/db-theme). You can start without it: the whitelabel theme works right away, and you add the DB Theme later.

</DBSection>

## Styling setup

First import a theme – it carries all tokens as CSS custom properties and handles Light Mode and Dark Mode. Then import the bundle with the helper classes.

```css
/* index.css */
@layer whitelabel-theme, db-ux;

@import '@db-ux/core-foundations/build/styles/theme/rollup.css' layer(whitelabel-theme);
@import '@db-ux/core-foundations/build/styles/bundle.css' layer(db-ux);
```

The bundle applies two defaults: density `regular` and adaptive coloring `neutral-bg-lvl-1`.

### Pick the asset path variant

| Variant        | Asset path                        | Use when                                             |
| -------------- | --------------------------------- | ---------------------------------------------------- |
| `rollup.css`   | `@db-ux/core-foundations/assets`  | Your bundler resolves package paths                  |
| `webpack.css`  | `~@db-ux/core-foundations/assets` | You build with Webpack                               |
| `relative.css` | `../../assets`                    | You copy icons and fonts into your own public folder |

### Optional helper classes

Each of these makes one group of data attributes available everywhere. Import only what you use.

```css
/* Use [data-divider] and [data-focus] everywhere */
@import '@db-ux/core-foundations/build/styles/helpers/classes/all.css' layer(db-ux);
/* Use [data-density] everywhere */
@import '@db-ux/core-foundations/build/styles/density/classes/all.css' layer(db-ux);
/* Use [data-font-size] everywhere */
@import '@db-ux/core-foundations/build/styles/fonts/classes/all.css' layer(db-ux);
/* Use [data-color] everywhere */
@import '@db-ux/core-foundations/build/styles/colors/classes/all.css' layer(db-ux);
```

## First token

Reference tokens as CSS custom properties.

```css
.my-container {
	padding: var(--db-spacing-fixed-md);
}
```

Density and color are set through data attributes on a container and passed down to its children.

```html
<div class="my-container" data-density="functional" data-color="successful-bg-lvl-1"></div>
```

All available tokens are listed under [Foundation](/documentation/foundation).

</DBSection>

## Check your setup

Add this snippet to a page. It shows in one place whether tokens, font and icons load.

```html
<div style="padding: var(--db-spacing-fixed-md)">
	<span data-icon="arrow_right">Text with icon</span>
</div>
```

| Check  | Expected                                                                                                          | If not                                                                                                                                                        |
| ------ | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tokens | The container has a padding of 16 px in the DevTools.                                                             | The theme import is missing. Without it, `var()` has no value and the padding is 0.                                                                           |
| Font   | In the browser DevTools, the rendered font of the text is `OpenSans` – or `DB Neo Screen Sans` with the DB Theme. | The browser cannot find the font files. Check the asset paths from the styling setup.                                                                         |
| Icon   | An arrow appears in front of the text.                                                                            | The browser cannot find the icon font. In the Network tab of the DevTools, a request for a `.woff2` file fails. Check the asset paths from the styling setup. |

</DBSection>

## Recommended tooling

Neither package is required to get started. Add them once your first token resolves.

### PostCSS plugin

Reduces the bundle size by resolving `var()`, `calc()`, `color-mix()` and `light-dark()` at build time and removing unused declarations.

```shell
pnpm add @db-ux/core-postcss-plugin --save-dev
```

### Stylelint plugin

Checks your own CSS and SCSS against the design system rules, for example whether you reference tokens instead of fixed values.

```shell
pnpm add @db-ux/core-stylelint --save-dev
```

## Troubleshooting

| Symptom                              | Cause and fix                                                                                                    |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Custom properties resolve to nothing | No theme is imported. The theme file defines the tokens – the bundle alone is not enough.                        |
| Icons and fonts do not load          | The asset path variant does not match your setup. Switch between `rollup.css`, `webpack.css` and `relative.css`. |
| Data attributes have no effect       | The matching helper class file is not imported. Add the import for that group.                                   |

If none of this helps, open an issue in the [core-web repository](https://github.com/db-ux-design-system/core-web/issues/new/choose). Please check first whether the issue already exists.
