## Before you begin

You need:

- A React project. The examples use Vite, but any bundler that imports CSS from npm packages works. The showcases in the core-web repository run on React 19.
- Node.js and a package manager. The commands on this page use pnpm. With npm, use `npm i` instead of `pnpm add`.
- A supported browser: the last three versions of Chrome and Edge, Firefox ESR and the last two major versions of Safari.

For products of Deutsche Bahn, you also need access to the Marketing Portal for the [DB Theme](/documentation/get-started/development/packages/db-theme). You can start without it: the whitelabel theme works right away, and you add the DB Theme later.

</DBSection>

<DBSection spacing="small" width="auto">

## Install

```shell
pnpm add @db-ux/react-core-components @db-ux/core-components @db-ux/core-foundations
```

The component package needs both style packages. `@db-ux/core-components` carries the component styles, `@db-ux/core-foundations` the tokens and assets underneath them.

</DBSection>

<DBSection spacing="small" width="auto">

## Styling setup

Pick one of the two options. The Vite plugin is shorter, the manual import works in every bundler.

### With Vite

```shell
pnpm add @db-ux/core-vite-plugin --save-dev
```

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import dbUxPlugin from '@db-ux/core-vite-plugin';

export default defineConfig({
	plugins: [dbUxPlugin()],
});
```

```css
/* index.css */
@import '@db-ux/core-vite-plugin/index.css';
```

### Without Vite

```css
/* index.css */
@layer whitelabel-theme, db-ux;

@import '@db-ux/core-foundations/build/styles/theme/rollup.css' layer(whitelabel-theme);
@import '@db-ux/core-components/build/styles/bundle.css' layer(db-ux);
```

The `rollup` variant resolves asset paths against the package. Use `webpack.css` for Webpack and `relative.css` if you copy icons and fonts into your own `public` folder.

## Check your setup

Render a button with an icon. It shows in one place whether styles, font and icons load.

```tsx
import { DBButton } from '@db-ux/react-core-components';

<DBButton variant="brand" icon="arrow_right">
	Add item to cart
</DBButton>;
```

| Check  | Expected                                                                                                            | If not                                                                                                                                                        |
| ------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Styles | The button has a filled background in the brand color and rounded corners.                                          | The CSS import is missing, or the theme is loaded after the component styles.                                                                                 |
| Font   | In the browser DevTools, the rendered font of the button is `OpenSans` – or `DB Neo Screen Sans` with the DB Theme. | The browser cannot find the font files. Check the asset paths from the styling setup.                                                                         |
| Icon   | An arrow appears in front of the text.                                                                              | The browser cannot find the icon font. In the Network tab of the DevTools, a request for a `.woff2` file fails. Check the asset paths from the styling setup. |

</DBSection>

## Recommended tooling

Neither package is required to get started. Add them once your first component renders.

### PostCSS plugin

Reduces the bundle size by resolving `var()`, `calc()`, `color-mix()` and `light-dark()` at build time and removing unused declarations.

```shell
pnpm add @db-ux/core-postcss-plugin --save-dev
```

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import { dbUxFlatten } from '@db-ux/core-postcss-plugin';

export default defineConfig({
	css: {
		transformer: 'postcss', // required for Vite 8+ (default: 'lightningcss')
		postcss: {
			plugins: [dbUxFlatten()],
		},
	},
});
```

### ESLint plugin

Reports incorrect component usage directly in the editor.

```shell
pnpm add eslint @db-ux/core-eslint-plugin @typescript-eslint/parser --save-dev
```

## Troubleshooting

| Symptom                           | Cause and fix                                                                                                                                                         |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Components render without styles  | The CSS import is missing, or the theme is loaded after the component styles. Check that `@layer whitelabel-theme, db-ux;` is the first statement in your stylesheet. |
| Icons and fonts do not load       | The asset path does not match your bundler. Switch between `rollup.css`, `webpack.css` and `relative.css`.                                                            |
| CSS output looks broken on Vite 8 | Vite 8 minifies with LightningCSS, which transforms modern CSS such as `light-dark()` incorrectly. Set `css.transformer: 'postcss'`.                                  |

If none of this helps, open an issue in the [core-web repository](https://github.com/db-ux-design-system/core-web/issues/new/choose). Please check first whether the issue already exists.
