## How the packages relate to each other

Three layers build on each other. You only install the top layer you need – the ones below come with it.

| Layer                | Package                                                                      | Contains                                                  |
| -------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------- |
| Framework components | `@db-ux/react-core-components` and the Angular, Vue and Web Components twins | Components for one framework                              |
| Component styles     | `@db-ux/core-components`                                                     | CSS and SCSS for all components, includes the layer below |
| Tokens and assets    | `@db-ux/core-foundations`                                                    | Colors, spacing, typography, density, icons, fonts        |

<DBNotification variant="standalone" semantic="informational" headline="Note">
	`@db-ux/core-components` pulls in `@db-ux/core-foundations` as a dependency. With `npm` that
	happens automatically. With `pnpm` you install both explicitly.
</DBNotification>

## Themes and assets

All framework package guides use the whitelabel theme in their styling setup, because it works without further access. Products of Deutsche Bahn additionally need the DB Theme. Theme and icons are encrypted and need credentials from the Marketing Portal.

| Target                  | Install                 | Guide                                                                             |
| ----------------------- | ----------------------- | --------------------------------------------------------------------------------- |
| Deutsche Bahn brand     | `@db-ux/db-theme`       | [DB Theme](/documentation/get-started/development/packages/db-theme)              |
| S-Bahn brand            | `@db-ux/s-bahn-theme`   | [DB Theme](/documentation/get-started/development/packages/db-theme#s-bahn-theme) |
| Icons without the theme | `@db-ux/db-theme-icons` | [Icons](/documentation/get-started/development/packages/icons)                    |

<DBNotification

## Optional tooling

None of these are needed to get started. Add them once your first component renders.

| Package                      | Purpose                                                                                                  | Recommendation                    |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `@db-ux/core-postcss-plugin` | Resolves `var()`, `calc()`, `color-mix()` and `light-dark()` at build time and drops unused declarations | Recommended for production builds |
| `@db-ux/core-vite-plugin`    | Reduces the CSS setup to a single import                                                                 | Recommended when you use Vite     |
| `@db-ux/core-eslint-plugin`  | Reports incorrect component usage in your editor                                                         | Optional, but helpful in teams    |
| `@db-ux/core-stylelint`      | Checks your CSS and SCSS against the design system rules                                                 | Optional                          |

For AI coding agents, use `@db-ux/mcp-server` and `@db-ux/agent-cli`. Both are covered on the [MCP Server](/documentation/learn/mcp-server) page.

</DBSection>
