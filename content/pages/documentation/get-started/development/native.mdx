## Current state

<DBNotification variant="standalone" semantic="warning" headline="In development – no release yet">
	Neither library has a published release. There is no installation guide for products yet. The
	repositories describe how to set up the project for contribution, not how to use it in an app.
</DBNotification>

| Platform | Technology                      | Minimum version | Repository                                                          |
| -------- | ------------------------------- | --------------- | ------------------------------------------------------------------- |
| iOS      | SwiftUI, Swift Package `DBUXDS` | iOS 18          | [core-ios](https://github.com/db-ux-design-system/core-ios)         |
| Android  | Jetpack Compose                 | Android API 30  | [core-android](https://github.com/db-ux-design-system/core-android) |

Both libraries are split into **Foundation** – colors, typography, spacing as tokens – and **Components**.

</DBSection>
