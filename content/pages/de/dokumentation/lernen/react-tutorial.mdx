In diesem Tutorial baust du ein Kontaktformular mit Name, E-Mail, Thema und Nachricht. Nach dem Absenden bestätigt eine Meldung den Versand. Unterwegs richtest du die Styles ein, kombinierst Layout- und Formular-Komponenten und ergänzt eigenes CSS mit Tokens.

Jeder Schritt endet mit einer Prüfung. So weißt du, dass der Schritt funktioniert hat, bevor du weitermachst.

Dasselbe Formular gestaltet das [Figma-Tutorial](/de/dokumentation/lernen/figma-tutorial) in Figma.

## Bevor du anfängst

Du brauchst:

- Node.js und pnpm. Mit npm verwendest du `npm create` und `npm i` statt `pnpm create` und `pnpm add`.
- Grundkenntnisse in React: Komponenten, JSX und den Hook `useState`.
- Einen unterstützten Browser: die letzten drei Versionen von Chrome und Edge, Firefox ESR und die letzten zwei Major-Versionen von Safari.

Das Tutorial wurde mit Vite 8, React 19 und Version 6 der Pakete des Design Systems getestet.

</DBSection>

<DBSection spacing="small" width="auto">

## Schritt 1: Projekt anlegen

Lege ein React-Projekt mit TypeScript an und starte es:

```shell
pnpm create vite my-app --template react-ts
cd my-app
pnpm install
pnpm dev
```

Lösche `src/App.css`. Die nächsten Schritte ersetzen die Styles der Vorlage.

**Prüfen:** Der Browser zeigt die Startseite von Vite unter der Adresse, die im Terminal steht, standardmäßig `http://localhost:5173`.

</DBSection>

<DBSection spacing="small" width="auto">

## Schritt 2: Pakete und Styles installieren

Installiere die React-Komponenten und beide Style-Pakete:

```shell
pnpm add @db-ux/react-core-components @db-ux/core-components @db-ux/core-foundations
```

Ersetze den Inhalt von `src/index.css`:

```css
/* src/index.css */
@layer whitelabel-theme, db-ux;

@import '@db-ux/core-foundations/build/styles/theme/rollup.css' layer(whitelabel-theme);
@import '@db-ux/core-components/build/styles/bundle.css' layer(db-ux);
```

Die erste Zeile legt die Reihenfolge der Cascade Layers fest. So kommt das Theme immer vor den Styles der Komponenten.

Vite 8 minifiziert CSS standardmäßig mit LightningCSS. Es wandelt die Funktion `light-dark()` des Design Systems falsch um, und im Produktions-Build stimmen die Farben nicht mehr. Stelle den Minifier auf esbuild um:

```shell
pnpm add esbuild --save-dev
```

```ts
// vite.config.ts
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
	plugins: [react()],
	build: {
		cssMinify: 'esbuild',
	},
});
```

**Prüfen:** Die Befehle laufen ohne Fehler durch. Das Ergebnis siehst du im nächsten Schritt, sobald die Seite die ersten Komponenten nutzt.

</DBSection>

<DBSection spacing="small" width="auto">

## Schritt 3: Seitenstruktur aufbauen

Ersetze den Inhalt von `src/App.tsx`:

```tsx
// src/App.tsx
import { DBHeadingH1, DBSection, DBStack } from '@db-ux/react-core-components';

const App = () => (
	<DBSection spacing="medium" width="small">
		<DBStack gap="large">
			<DBHeadingH1>Kontakt</DBHeadingH1>
		</DBStack>
	</DBSection>
);

export default App;
```

- **Section** setzt den äußeren Abstand und begrenzt die Breite des Inhalts. Mit `width="small"` bleibt das Formular gut lesbar.
- **Stack** ordnet seine Kinder mit gleichmäßigem Abstand an. Du nutzt ihn gleich wieder für die Formularfelder.
- **Heading** rendert ein echtes `<h1>` mit der Typografie des Design Systems.

**Prüfen:** Die Seite zeigt die Überschrift „Kontakt“ in großer, fetter Schrift. Die Schrift ist `OpenSans` – du siehst sie in den DevTools unter den gerenderten Schriften. Erscheint die Überschrift in der Standardschrift des Browsers, fehlt der CSS-Import aus Schritt 2.

</DBSection>

<DBSection spacing="small" width="auto">

## Schritt 4: Formular ergänzen

Setze die Formularfelder in eine Card unter der Überschrift:

```tsx
// src/App.tsx
import {
	DBButton,
	DBCard,
	DBCheckbox,
	DBHeadingH1,
	DBInput,
	DBSection,
	DBSelect,
	DBStack,
	DBTextarea,
} from '@db-ux/react-core-components';

const App = () => (
	<DBSection spacing="medium" width="small">
		<DBStack gap="large">
			<DBHeadingH1>Kontakt</DBHeadingH1>

			<DBCard spacing="medium">
				<form>
					<DBStack gap="medium">
						<DBInput label="Name" name="name" required />
						<DBInput label="E-Mail" name="email" type="email" required />
						<DBSelect label="Thema" name="topic">
							<option value="booking">Buchung</option>
							<option value="refund">Erstattung</option>
							<option value="other">Sonstiges</option>
						</DBSelect>
						<DBTextarea label="Nachricht" name="message" required />
						<DBCheckbox name="copy">Kopie an mich senden</DBCheckbox>
						<DBButton type="submit" variant="brand" icon="arrow_right">
							Nachricht senden
						</DBButton>
					</DBStack>
				</form>
			</DBCard>
		</DBStack>
	</DBSection>
);

export default App;
```

Jede Formular-Komponente rendert ein natives Formularelement mit seinem Label. Deshalb gehört `label` zu jedem Feld: Screenreader lesen es vor, und ein Klicke auf das Label setzt den Fokus ins Feld. `required` und `type="email"` nutzen die Validierung des Browsers.

**Prüfen:** Die Card zeigt fünf Felder und einen Button in der Markenfarbe mit Pfeil-Icon. Ein Klicke auf ein Label setzt den Fokus ins Feld. Fehlt der Pfeil, kann der Browser die Icon-Schrift nicht laden – suche im Netzwerk-Tab der DevTools nach einer fehlgeschlagenen Anfrage für eine `.woff2`-Datei.

</DBSection>

<DBSection spacing="small" width="auto">

## Schritt 5: Rückmeldung nach dem Absenden zeigen

Merke dir, ob das Formular abgeschickt wurde, und zeige in diesem Fall eine Meldung. Das ist die vollständige `src/App.tsx`:

```tsx
// src/App.tsx
import { useState, type FormEvent } from 'react';
import {
	DBButton,
	DBCard,
	DBCheckbox,
	DBHeadingH1,
	DBInput,
	DBNotification,
	DBSection,
	DBSelect,
	DBStack,
	DBTextarea,
} from '@db-ux/react-core-components';

const App = () => {
	const [sent, setSent] = useState(false);

	const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
		event.preventDefault();
		setSent(true);
	};

	return (
		<DBSection spacing="medium" width="small">
			<DBStack gap="large">
				<DBHeadingH1>Kontakt</DBHeadingH1>

				{sent && (
					<DBNotification
						variant="standalone"
						semantic="successful"
						headline="Nachricht gesendet"
						closeable
						closeButtonText="Schließen"
						onClose={() => setSent(false)}
					>
						Wir melden uns innerhalb von zwei Werktagen bei dir.
					</DBNotification>
				)}

				<DBCard spacing="medium">
					<form onSubmit={handleSubmit}>
						<DBStack gap="medium">
							<DBInput label="Name" name="name" required />
							<DBInput label="E-Mail" name="email" type="email" required />
							<DBSelect label="Thema" name="topic">
								<option value="booking">Buchung</option>
								<option value="refund">Erstattung</option>
								<option value="other">Sonstiges</option>
							</DBSelect>
							<DBTextarea label="Nachricht" name="message" required />
							<DBCheckbox name="copy">Kopie an mich senden</DBCheckbox>
							<div className="form-actions">
								<DBButton type="submit" variant="brand" icon="arrow_right">
									Nachricht senden
								</DBButton>
							</div>
						</DBStack>
					</form>
				</DBCard>
			</DBStack>
		</DBSection>
	);
};

export default App;
```

Die Meldung hat die Rolle `status`. Screenreader sagen sie an, ohne den Fokus zu verschieben. Mit `closeButtonText` legst du den zugänglichen Namen des Schließen-Buttons fest, ohne die Angabe ist er englisch. Das ESLint-Plugin des Design Systems meldet eine schließbare Meldung ohne diesen Text. Den Wrapper `form-actions` um den Button brauchst du im nächsten Schritt.

**Prüfen:**

- Schicke das leere Formular ab: Der Browser markiert das erste Pflichtfeld, und es erscheint keine Meldung.
- Fülle Name, E-Mail und Nachricht aus und schicke erneut ab: Über der Card erscheint die grüne Meldung „Nachricht gesendet“.
- Schließe die Meldung mit dem Button „Schließen“: Sie verschwindet.

</DBSection>

<DBSection spacing="small" width="auto">

## Schritt 6: Eigene Styles mit Tokens ergänzen

Richte den Button am Ende des Formulars aus. Ergänze diese Regel in `src/index.css` unter den Imports:

```css
/* src/index.css */
.form-actions {
	display: flex;
	justify-content: flex-end;
	padding-block-start: var(--db-spacing-fixed-sm);
}
```

`--db-spacing-fixed-sm` ist ein Abstands-Token der Foundation. Nutze für Abstände, Farben und Größen Tokens statt fester Pixelwerte, damit deine Styles dem Theme und der Density folgen. Alle Tokens findest du unter [Foundation](/de/dokumentation/foundation).

**Prüfen:** Der Button sitzt am rechten Rand der Card, mit etwas mehr Abstand nach oben.

</DBSection>

## Schritt 7: Für die Produktion bauen

```shell
pnpm build
pnpm preview
```

**Prüfen:** Die Vorschau unter `http://localhost:4173` sieht genauso aus wie die Entwicklungsversion. Stelle dein Betriebssystem auf Dark Mode um: Seite, Card und Felder wechseln in beiden Versionen auf dunkle Farben. Stimmen die Farben nur in der Vorschau nicht, fehlt die Einstellung `cssMinify` aus Schritt 2.
