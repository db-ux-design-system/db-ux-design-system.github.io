## Nur Tokens, keine Komponenten

Nutze sie für eigene Komponenten oder nur für Icons und Schriften. Mit Komponenten folgst du dem [Setup für HTML und CSS](/de/dokumentation/lernen/html-css-einrichten 'Enthält die Foundation.').

<LearnAside>

- **Formate:** CSS, SCSS und Tailwind.
- **Paketmanager:** Die Befehle auf dieser Seite nutzen pnpm. Mit npm nutzt du `npm i` statt `pnpm add`.
- **Browser:** die letzten drei Versionen von Chrome und Edge, Firefox ESR und die letzten zwei Major-Versionen von Safari.
- **DB Theme:** Produkte der Deutschen Bahn brauchen zusätzlich das DB Theme aus dem Marketingportal. Du kannst ohne anfangen, denn das Whitelabel-Theme funktioniert sofort.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Installiere ein Paket

`@db-ux/core-foundations` enthält alle Tokens und Assets: Farben, Abstände, Typografie, Density, Icons und Schriften.

```shell
pnpm add @db-ux/core-foundations
```

</LearnBlock>

<LearnBlock>

## Lade das Theme vor dem Bundle

Das Theme enthält alle Tokens als CSS Custom Properties für Light Mode und Dark Mode. Das Bundle ergänzt die Helper-Klassen.

```css
/* index.css */
@layer whitelabel-theme, db-ux;
@import '@db-ux/core-foundations/build/styles/theme/rollup.css' layer(whitelabel-theme);
@import '@db-ux/core-foundations/build/styles/bundle.css' layer(db-ux);
```

<LearnAside>

Das Bundle setzt zwei Standardwerte: Density `regular` und Adaptive Coloring `neutral-bg-lvl-1`.

### Die passende Asset-Pfad-Variante

| Variante       | Asset-Pfad                        | Nutze sie, wenn …                                                 |
| -------------- | --------------------------------- | ----------------------------------------------------------------- |
| `rollup.css`   | `@db-ux/core-foundations/assets`  | dein Bundler Paketpfade auflöst                                   |
| `webpack.css`  | `~@db-ux/core-foundations/assets` | du mit Webpack baust                                              |
| `relative.css` | `../../assets`                    | du Icons und Schriften in deinen eigenen `public`-Ordner kopierst |

### DB Theme

Der Import lädt das Whitelabel-Theme. Produkte der Deutschen Bahn brauchen zusätzlich das [DB Theme](/de/dokumentation/lernen/db-theme-einrichten).

</LearnAside>

</LearnBlock>

## Ergänze Helper-Klassen nur, wo du sie brauchst

Jede Datei mit Helper-Klassen macht eine Gruppe von Data-Attributen überall verfügbar. Importiere nur die Gruppen, die du nutzt.

```css
@import '@db-ux/core-foundations/build/styles/density/classes/all.css' layer(db-ux);
```

<LearnAside>

```css
/* [data-divider] und [data-focus] überall nutzen */
@import '@db-ux/core-foundations/build/styles/helpers/classes/all.css' layer(db-ux);
/* [data-density] überall nutzen */
@import '@db-ux/core-foundations/build/styles/density/classes/all.css' layer(db-ux);
/* [data-font-size] überall nutzen */
@import '@db-ux/core-foundations/build/styles/fonts/classes/all.css' layer(db-ux);
/* [data-color] überall nutzen */
@import '@db-ux/core-foundations/build/styles/colors/classes/all.css' layer(db-ux);
```

</LearnAside>

## Prüfe das Setup mit einem ersten Token

Ein Container mit einem Abstands-Token und einem Icon zeigt an einer Stelle, ob Tokens, Schrift und Icons laden.

```html
<div style="padding: var(--db-spacing-fixed-md)">
	<span data-icon="arrow_right">Text mit Icon</span>
</div>
```

<LearnAside>

| Prüfung | Erwartet                                                                                            |
| ------- | --------------------------------------------------------------------------------------------------- |
| Tokens  | Der Container hat in den DevTools einen Innenabstand von 16 px.                                     |
| Schrift | Die DevTools zeigen `OpenSans` als gerenderte Schrift – oder `DB Neo Screen Sans` mit dem DB Theme. |
| Icon    | Vor dem Text erscheint ein Pfeil.                                                                   |

### Tokens in deinem eigenen CSS

Referenziere Tokens als CSS Custom Properties:

```css
.my-container {
	padding: var(--db-spacing-fixed-md);
}
```

Density und Farbe setzt du über Data-Attribute an einem Container, der sie an seine Kinder weitergibt:

```html
<div class="my-container" data-density="functional" data-color="successful-bg-lvl-1"></div>
```

Alle verfügbaren Tokens findest du unter [Foundation](/de/dokumentation/foundation).

</LearnAside>

## Wenn etwas nicht richtig aussieht

Die meisten Probleme beim Setup kommen von einem fehlenden Theme-Import oder von Asset-Pfaden, die nicht zu deinem Setup passen.

<LearnAside>

| Symptom                               | Ursache und Lösung                                                                                                                                                             |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Custom Properties lösen zu nichts auf | Es ist kein Theme importiert. Die Theme-Datei definiert die Tokens – das Bundle allein genügt nicht. Ohne sie ist der Innenabstand 0.                                          |
| Schrift oder Icons fehlen             | Der Browser findet die Asset-Dateien nicht. Im Network-Tab schlägt eine Anfrage für eine `.woff2`-Datei fehl. Wechsle zwischen `rollup.css`, `webpack.css` und `relative.css`. |
| Data-Attribute haben keine Wirkung    | Die passende Datei mit Helper-Klassen ist nicht importiert. Ergänze den Import für diese Gruppe.                                                                               |

Wenn nichts davon hilft, eröffne ein Issue im [core-web-Repository](https://github.com/db-ux-design-system/core-web/issues/new/choose). Prüfe vorher, ob es das Issue schon gibt.

</LearnAside>

<LearnAside>

Keines der beiden Plugins brauchst du für den Start. Ergänze sie, sobald dein erstes Token auflöst.

### PostCSS-Plugin

Reduziert die Bundle-Größe, indem es `var()`, `calc()`, `color-mix()` und `light-dark()` zur Build-Zeit auflöst und ungenutzte Deklarationen entfernt.

```shell
pnpm add @db-ux/core-postcss-plugin --save-dev
```

### Stylelint-Plugin

Prüft dein eigenes CSS und SCSS gegen die Regeln des Design Systems, zum Beispiel ob du Tokens statt fester Werte referenzierst.

```shell
pnpm add @db-ux/core-stylelint --save-dev
```
