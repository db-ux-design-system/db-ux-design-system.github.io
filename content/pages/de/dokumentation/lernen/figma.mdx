## Property-Namen zeigen ihren Zweck

Jede Property in der Figma-Bibliothek beginnt mit einem Icon für ihren Typ. Toggles wie das Pflichtfeld-Sternchen funktionieren genauso – mit einer Ausnahme bei Auswahl-Elementen in Full Width.

<LearnAside>

### Property Icons

| Icon | Zweck                                          | Beispiel        |
| ---- | ---------------------------------------------- | --------------- |
| 👁️   | Anzeigen/Ausblenden (schaltet Sichtbarkeit um) | `👁️ Show Label` |
| 🔀   | Variantenauswahl                               | `🔀 Variant`    |
| 📦   | Slot (Inhaltsbereich)                          | `📦 Children`   |
| 🔄   | Icon-Swap (Instance Swap für Icons)            | `🔄 Icon`       |
| ✏️   | Text-Override                                  | `✏️ Label`      |
| ⚙️   | Code-Connect-Property (wirkt nur im Code)      | `⚙️ Required`   |

## Hilfskomponenten erweitern eine Instanz

**Floating Container**, **Resizer** und **Scrollbar** stecken in anderen Komponenten. Sie legen Elemente über eine Komponente, machen feste Größen überschreibbar und zeigen eine dekorative Scrollbar.

<LearnAside>

### Floating Container

Mit dem 🛟 Floating Container platzierst du zusätzliche Elemente wie Badge, Tooltip oder Popover an einer Trigger- bzw. Parent-Komponente.

<div className="guideline-examples">
<GuidelineExample

	figmaUrl="https://embed.figma.com/design/Dr7QvFYRn5AwyQVOto4pEz/Doku--Scrollbar?node-id=7074-3625&embed-host=share"
/>

<div>
<DBNotification variant="standalone" semantic="informational" headline="Verwendet in:" style={{marginBlockEnd: 'var(--db-spacing-fixed-xl)'}}>
Buttons, Navigation Items
</DBNotification>

- Floating Container einblenden
- Bei Bedarf weitere Floating Items ergänzen – Tipp: vorhandenes Item duplizieren
  - Manuelle Einstellungen: `full width`, `full height`, `absolute position`, Constraints `Left + Right`, `Top + Bottom`
- Position-Property: `top-start`, `top-center`, `top-end`, `middle-start`, `middle-end`, `bottom-start`, `bottom-center` oder `bottom-end`
- Edge-Property: `outside` (von der Parent-Komponente weg), `center` (am Anchor zentriert) oder `inside` (in die Parent-Komponente hinein)

</div>
</div>

## Lass Text wie im Code umbrechen

In Figma brechen Textebenen oft anders um als in der programmierten Komponente. Stelle das Breitenverhalten der Textebene zwischen **Hug** und **Fill** um, oder nutze die Property `🔀 Multiline`, wo es sie gibt.

<LearnAside>

### Breadcrumb

#### Lange Labels im Popover Item

In der programmierten Komponente wächst das Popover mit seinem Inhalt, sodass lange Labels einzeilig bleiben. In Figma brechen die Labels standardmäßig um. Setze das Breitenverhalten der betroffenen Ebenen auf „Hug“, damit das Verhalten in Figma dem Code entspricht.

<GuidelineExample
	fullWidth

	description="Wähle die betroffenen Ebenen aus und ändere das Breitenverhalten von „Fill“ auf „Hug contents“, damit das Verhalten dem Code entspricht"
/>

### Button

#### Mehrzeiliger Text in Buttons mit Full Width

<DBNotification variant="standalone" semantic="informational">
	Verwende mehrzeiligen Text nur in Ausnahmefällen, z. B. wenn der Text durch eine Übersetzung
	länger wird.
</DBNotification>

Für automatische Zeilenumbrüche in einem Button mit Full Width wählst du die Ebene „Text“ im Button aus und änderst das Breitenverhalten von „Hug“ auf „Fill“.

## Lass Inhalte wie im Code wachsen

Ist ein Inhalt höher oder breiter, als die Komponente erwartet, läuft er in Figma über oder verdeckt andere Bereiche. Stelle das Größenverhalten des betroffenen Containers von **Fill** auf **Hug** um – oder umgekehrt.

<LearnAside>

### Textarea

#### Vertikales Größenverhalten

<GuidelineExample
	figmaUrl="https://embed.figma.com/design/2gF67xeMuiyGIlW6lHHNC1/Doku--Textarea-%E2%9C%85?node-id=4884-2&embed-host=share"
	layout="side"
>
Passe nach dem Platzieren der Komponente und dem Setzen der Properties die Größe an und setze das vertikale Größenverhalten auf „Fill Container“ für:

- Container
- Textarea Container

</GuidelineExample>

### Pagination

#### Sonderfall Zeilenumbruch

Der Slot `📦 Children` ist auf Hug gestellt, die Reihe kann daher nicht umbrechen. Ist die Pagination schmaler, als die Reihe braucht, laufen die Items aus der Komponente heraus, statt in eine zweite Zeile zu rutschen. Zwei Schritte ermöglichen den Umbruch.

<GuidelineExample
	figmaUrl="https://embed.figma.com/design/diQoICeEsfVztFnf55Fufq/Doku--Pagination?node-id=2025-4&embed-host=share"
	fullWidth
/>

- Beide Instanzen `Icon Button → Ghost` auf Ebene der Pagination ausblenden und als erstes und letztes Element in den Slot `📦 Children` einfügen
- Das Breitenverhalten des Containers `📦 Children` von Hug auf Fill stellen

### Custom Select

#### Sonderfall Mobile Landscape

Setze „Dropdown Height“ von „(Def) Auto“ auf „Fill“, um die Höhe des Dropdowns bei wenig Platz im Viewport zu begrenzen, etwa in Mobile Landscape.

### Control Panel & Shell

#### Scrollverhalten von vertikaler Navigation und Meta

In der vertikalen Navigation dockt die Meta-Navigation am unteren Rand an. Das gilt für die Varianten Drill Down und Tree.

Füllen viele Navigation Items den verfügbaren Platz, laufen sie unter die Meta-Navigation, statt sie zu verdrängen. Ändere in Figma das Auto-Layout-Verhalten der Navigation von Fill auf Hug. Dann bleibt die Meta-Navigation unter allen Navigation Items und wird von der Navigation aus dem sichtbaren Bereich geschoben.

	description="Wähle die Ebene CP Navigation aus und ändere das vertikale Größenverhalten von Fill container auf Hug contents"

#### Shell Content Auto: Inhalt im Children Slot überlagert den End Slot

In der Variante `Auto` von Shell Content dockt der `End Slot` am unteren Rand an. Dafür ist das Höhenverhalten des Slots `Children` im Auto Layout initial auf Fill gesetzt.

Wird der Inhalt höher als der verfügbare Platz, überlagert er in Figma den `End Slot`. Ändere dann das Höhenverhalten des Slots `Children` von `Fill` auf `Hug`, damit der `End Slot` unter dem Inhalt bleibt.

## Stelle die Ausrichtung an der Ebene ein

Manche Ausrichtungen sind keine Component Properties. Du stellst sie direkt an der Ebene in der Komponente ein – bei der Heading, den Slots im Dialog Header und dem Pfeil des Tooltips.

<LearnAside>

### Heading

#### Alignment einstellen

Das Alignment steht nicht mehr als Component Property zur Verfügung. Für ein anderes Alignment als „Left“ stellst du es direkt an der Ebene innerhalb der Komponente ein.

### Dialog

#### Ausrichtung der Slot-Inhalte zum Close-Button

Start Slot und End Slot des Dialog Headers richten ihren Inhalt an der Höhe des Close-Buttons aus. Für welche Elemente das relevant wird, hängt von ihrer Höhe ab.

<GuidelineExample
	figmaUrl="https://embed.figma.com/design/TBG73nKNPgXcLTluGz6dLM/Doku--Dialog?node-id=2025-4&embed-host=share"
	fullWidth
/>

- Elemente **kleiner als `sizing-md`** (Höhe des Close-Buttons): Container mit `min-height=sizing-md` und vertikaler Zentrierung
- Elemente **höher als `sizing-md`**: Container mit `padding-top=spacing-X` (abhängig von der Höhe des Elements in der ersten Zeile), sodass die erste Zeile vertikal zum Close-Button zentriert bleibt

## Logo und Overflow im Control Panel

Das Plugin **DB Logo Importer** setzt ein markenkonformes Logo mit Logozusatz in das Control Panel. Bei der horizontalen Popover Navigation zeigst du entweder den Overflow oder den ausgeklappten Zustand – nicht beides.

<LearnAside>

### Control Panel & Shell

#### Eigenes Logo mit dem DB Logo Importer hinzufügen

<DBNotification variant="standalone" semantic="informational">
	Erstelle dein markenkonformes Logo-SVG über das Marketingportal. Der Plugin-Import stellt
	systemkonforme Farbvariablen und Größen sicher.
</DBNotification>

Im Brand-Bereich des Control Panels kannst du nur in der Variante **Brand → Logozusatz** ein markenkonformes eigenes Logo mit Logozusatz hinzufügen. Nutze das Figma-Plugin <DBLink href="https://www.figma.com/community/plugin/1590462040996560100/concept-db-logo-importer" target="_blank" rel="noopener noreferrer" variant="inline">DB Logo Importer</DBLink>, um ein SVG aus dem <DBLink href="https://marketingportal.extranet.deutschebahn.com/marketingportal/Marke-und-Design/Basiselemente/Logo/Logozusatz-mit-Tool#unit=Regio&mode=unit&breaking=true" target="_blank" rel="noopener noreferrer" variant="inline">DB Markenlogo-Generator</DBLink> zu importieren. Das Plugin weist die korrekten Farbvariablen zu und platziert das Logo direkt im **Logo Slot**.

#### Popover Navigation Horizontal: Overflow-Buttons

<DBNotification variant="standalone" semantic="informational">
	Nur Desktop – Mobile Popover Horizontal ist auf die Sub Navigation (Level 2) mit einer einzelnen
	Ebene begrenzt und zeigt keine Overflow-Buttons, keinen Active Indicator und keine ausgeklappten
	Popover Items.
</DBNotification>

Die Einstellung **Clip Content**, die für korrektes horizontales Overflow-Verhalten nötig ist, entfernt alle Elemente außerhalb des Children-Containers der Popover Navigation – einschließlich ausgeklappter Popover Items und des Active Indicators (Level 1). Zeige entweder das Overflow-Verhalten oder den ausgeklappten bzw. aktiven Zustand, nicht beides gleichzeitig.
