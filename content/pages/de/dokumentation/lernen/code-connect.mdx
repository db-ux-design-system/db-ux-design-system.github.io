## Eigenschaften in Figma steuern den Code

Code Connect verknüpft die Komponenten in Figma mit ihrem Code. Im Dev Mode sehen Entwickler:innen das Code-Snippet, das zur gewählten Konfiguration einer Komponente passt.

<LearnAside>

Das Design System nutzt in Figma zwei Arten von Eigenschaften:

1. **Design-Eigenschaften** verändern das Erscheinungsbild und sind immer auf der ersten Ebene sichtbar, zum Beispiel Size, Label oder Disabled.
2. **⚙️ Code-Connect-Eigenschaften** zählen nur für den generierten Code, nicht für das Design. Wenn du sie einstellen kannst, erscheinen sie auf der ersten Ebene mit einem ⚙️. Wenn nicht, werden sie im Hintergrund verarbeitet.

</LearnAside>

</LearnBlock>

<LearnBlock>

## ⚙️-Eigenschaften ändern nur den Code

Als Designer:in stellst du Design-Eigenschaften wie gewohnt ein. Eigenschaften mit **⚙️** stehen am Ende der Liste, haben vorausgewählte Standardwerte und verändern das Design nicht.

<LearnAside>

### Design-Eigenschaften

Das sind die Eigenschaften, die du siehst, wenn du eine Komponenteninstanz in Figma auswählst. Sie verändern das Erscheinungsbild der Komponente und zugleich den generierten Code.

### Checkbox: mit einstellbarer ⚙️-Eigenschaft

Die Checkbox zeigt Design-Eigenschaften wie `Checked`, `Indeterminate`, `Disabled`, `Validation`, `Show Required Asterisk`, `Show Label`, `Label` und `Show Message`. Am Ende der Liste lässt sich die ⚙️-Eigenschaft `Required` einstellen. Ihr Standardwert ist vorausgewählt.

<img
	src="/assets/learn/code-connect/design-properties.png"
	alt="Checkbox-Eigenschaften auf der ersten Ebene – Design-Eigenschaften und einstellbare ⚙️ Code-Connect-Eigenschaft (Required) sichtbar"
	style={{ maxWidth: '70%' }}
/>

### Outline Button: ohne ⚙️-Eigenschaften

Nicht jede Komponente hat einstellbare ⚙️-Eigenschaften. Der Outline Button zeigt nur Design-Eigenschaften wie `Disabled`, `Size`, `Width`, `Show Icon Leading`, `Show Icon Trailing`, `Icon Leading` und `Text`. Seine Variante wird automatisch an den Code übergeben.

	style={{ maxWidth: '70%' }}
/>

## Der ⚙️ Code Connect Layer enthält Werte nur für den Code

Manche Komponenten enthalten intern einen **⚙️ Code Connect** Layer für Eigenschaften, die es im Code gibt, aber nicht im Design. Wähle den Layer aus, um zu sehen, ob du etwas einstellen kannst.

<LearnAside>

<img
	src="/assets/learn/code-connect/code-connect-layer.png"
	alt="Der ⚙️ Code Connect Sub-Layer innerhalb einer Komponente im Figma-Layer-Panel"
	style={{ maxWidth: '40%' }}
/>

Der Layer zeigt einen von zwei Zuständen:

### ➡️ Set properties

Die Komponente hat einstellbare ⚙️-Eigenschaften. Sie erscheinen auf der ersten Ebene der Komponente, wo du sie anpasst. Standardwerte sind vorausgewählt.

<img
	src="/assets/learn/code-connect/set-properties.png"
	alt="Code Connect Layer mit einstellbaren Eigenschaften für die Checkbox"
	style={{ maxWidth: '50%' }}
/>

### ❌ No property to set

Die Komponente übergibt ihre Werte automatisch an den Code, beim Outline Button zum Beispiel `variant="outlined"`. Du musst nichts einstellen.

<img
	src="/assets/learn/code-connect/no-property.png"
	alt="Code Connect Layer mit der Meldung „No property to set“ für den Outline Button"
	style={{ maxWidth: '50%' }}
/>

</LearnAside>

## Lies das Snippet im Dev Mode

Als Entwickler:in wählst du im **Dev Mode** eine Komponenteninstanz aus und stellst im Bereich Code Connect des Inspect-Panels dein Framework ein. Das Snippet enthält jede Eigenschaft, auch ⚙️-Eigenschaften und ihre Standardwerte.

<LearnAside>

{/* TODO: This section needs review by a developer familiar with the Code Connect implementation. */}

1. Öffne eine Figma-Datei und wechsle über den Umschalter in der unteren Toolbar in den Dev Mode.
2. Wähle eine Komponenteninstanz auf der Canvas aus.
3. Im Inspect-Panel rechts findest du den Bereich Code Connect, markiert als „Connected“.
4. Wähle im Dropdown dein Ziel-Framework, zum Beispiel React.
5. Das Snippet zeigt die aktuell gesetzten Eigenschaften, einschließlich der Werte von ⚙️-Eigenschaften.

### Zuordnung der Eigenschaften

| Eigenschaftstyp        | Eingestellt durch                    | Beispiel-Eigenschaften                 | Im Code enthalten   |
| ---------------------- | ------------------------------------ | -------------------------------------- | ------------------- |
| Design-relevant        | Designer:in (erste Komponentenebene) | `size`, `label`, `disabled`            | ✅ Ja               |
| Nur Code (einstellbar) | Designer:in (⚙️ auf erster Ebene)    | `required`, `checked`, `indeterminate` | ✅ Ja               |
| Nur Code (automatisch) | Durch Variante bestimmt              | `variant`, `noText`                    | ✅ Ja (automatisch) |

Die Unterscheidung zählt nur für den Design-Workflow. Im Code werden alle Eigenschaften gleich behandelt.

### Standardwerte

⚙️-Eigenschaften haben Standardwerte. Hat eine Designerin oder ein Designer einen Wert nicht geändert, nutzt das Snippet den Standardwert. Das Snippet ist deshalb für die gewählte Konfiguration vollständig.

## Verbinde eigene Komponenten

Folge dem [Quickstart von Figma Code Connect](https://developers.figma.com/docs/code-connect/quickstart-guide/ 'Die offizielle Anleitung von Figma, um eigene Komponenten mit Code Connect zu verbinden.'), um eigene Komponenten zu verbinden.

<LearnAside>

Eine DB UX Komponente bindest du mit `instance.findInstance('DBButton').executeTemplate().example` in dein Snippet ein.

- Du brauchst einen gültigen Figma-Token mit Zugriff auf deine Komponente
- Der in Figma angezeigte Code ist ein String, du kannst ihn also beliebig anpassen
- Das Design System erzeugt die Snippets für alle Frameworks in seiner CI/CD-Pipeline mit dem [Figma-Plugin-Skript in core-web](https://github.com/db-ux-design-system/core-web/blob/main/packages/components/configs/plugins/figma/index.cjs). Du kannst dieses Skript einem KI-Coding-Agenten geben, um die Logik für deine eigenen Komponenten anzupassen.

</LearnAside>

</LearnBlock>
