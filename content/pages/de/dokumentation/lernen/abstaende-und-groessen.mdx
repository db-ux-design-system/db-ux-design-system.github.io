## Drei Arten von Tokens für Abstand und Größe

**Spacing fixed** für Außen-, Innenabstände und Lücken, **Spacing responsive** für Abstände, die mit dem Bildschirm wachsen, **Sizing** für feste Höhen. Ihre Werte folgen der Density und dem Theme.

<LearnAside>

| Art                | Größen                                     | Basis |
| ------------------ | ------------------------------------------ | ----- |
| Spacing fixed      | `3xs`, `2xs`, `xs`, `sm`, `md`, `lg`, `xl` | `md`  |
| Spacing responsive | `xs`, `sm`, `md`, `lg`, `xl`               | `md`  |
| Sizing             | `xs`, `sm`, `md`, `lg`, `xl`, `2xl`, `3xl` | `md`  |

Die Tokens gehören zum Theme und brauchen keinen eigenen Import.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Nutze Spacing fixed für die meisten Abstände

Außen-, Innenabstände und Lücken in Seiten und Komponenten nutzen **Spacing fixed**. Nutze Spacing-Tokens nicht für `width` oder `height`.

```css
.my-card {
	padding: var(--db-spacing-fixed-md);
	gap: var(--db-spacing-fixed-sm);
}
```

</LearnBlock>

<LearnBlock>

## Nutze Spacing responsive für Abstände im Layout

**Spacing responsive** ist auf großen Bildschirmen größer, zum Beispiel beim Innenabstand des Hauptbereichs. Die Komponente **Section** setzt es in deinem Seitenlayout schon für dich.

```css
.my-main {
	padding-inline: var(--db-spacing-responsive-md);
}
```

<LearnAside>

Nutze lieber `DBSection` als einen eigenen responsiven Innenabstand: Die Komponente wählt den passenden Abstand für jede Bildschirmgröße.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Nutze Sizing für feste Höhen

**Sizing** setzt die Höhe von Elementen, die mit Komponenten in einer Linie stehen, zum Beispiel ein eigenes Bedienelement neben einem Button.

```css
.my-control {
	block-size: var(--db-sizing-md);
}
```

<LearnAside>

Nutze Sizing nicht für Innen- oder Außenabstände. Ausnahme sind absolut positionierte Elemente in einer Komponente mit fester Höhe.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Nutze die Sass-Variablen

Mit Sass gibt es dieselben Tokens als Variablen.

```scss
@use '@db-ux/core-foundations/build/styles/variables';

.my-card {
	padding: variables.$db-spacing-fixed-md;
	block-size: variables.$db-sizing-md;
}
```

<LearnAside>

Die Variablen verweisen auf die CSS Custom Properties. Die Werte ändern sich also weiter mit Density und Theme.

</LearnAside>

</LearnBlock>
