## Den Kern brauchen alle, eine Erweiterung nur ein Bereich

Der **Kern** – Foundation und Komponenten – ist für jedes Produkt gleich. Eine **Erweiterung** baut darauf auf und ergänzt Standards für einen Bereich – du brauchst sie also nur, wenn dein Produkt in diesem Bereich arbeitet.

<LearnAside>

| Erweiterung          | Bereich                                           |
| -------------------- | ------------------------------------------------- |
| Reisendeninformation | Informationsstandards für Reisende                |
| DataViz              | Datenvisualisierung, derzeit in Beta              |
| Table                | Darstellung großer Datenmengen                    |
| Content              | einheitliche Kommunikation – noch nicht verfügbar |

Alle Erweiterungen stellt die Seite [Erweiterungen](/de/dokumentation/erweiterungen) vor.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Jede Erweiterung hat eigenes Material

Eine Erweiterung kann Figma-Bibliothek, Code und Dokumentation im Marketingportal mitbringen. Was es gibt, zeigt die [Übersicht](/de/dokumentation/erweiterungen 'Alle Erweiterungen und ihre Bereiche.').

<LearnAside>

| Erweiterung          | Design           | Code                                              | Dokumentation                                                                                                                                                               |
| -------------------- | ---------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reisendeninformation | Figma-Bibliothek | Web Components in GitLab (Anmeldung erforderlich) | [Marketingportal](https://marketingportal.extranet.deutschebahn.com/marketingportal/Design-Anwendungen/User-Experience/DB-UX-Design-System/extensions/reisendeninformation) |
| DataViz              | Figma-Bibliothek | Power-BI-Vorlagen und Code-Schnipsel für Plotly   | [Marketingportal](https://marketingportal.extranet.deutschebahn.com/marketingportal/Design-Anwendungen/User-Experience/DB-UX-Design-System/extensions/dataviz)              |
| Table                | –                | –                                                 | [Marketingportal](https://marketingportal.extranet.deutschebahn.com/marketingportal/Design-Anwendungen/User-Experience/DB-UX-Design-System/extensions/table)                |

Das Marketingportal erfordert eine Anmeldung. Deep Links funktionieren vor der Anmeldung nicht – öffne den Link nach dem Anmelden erneut.

</LearnAside>

</LearnBlock>

## Starte mit dem Kern

Richte erst den Kern ein, z. B. per [Figma-Einrichtung](/de/dokumentation/lernen/figma-einrichten 'Zugang zu den Figma-Bibliotheken.'). Ergänze dann Bibliothek und Code der Erweiterung aus den [Ressourcen](/de/dokumentation/ressourcen#erweiterungen 'Bibliotheken und Pakete der Erweiterungen.').

<LearnAside>

1. Richte zuerst den Kern ein – im [Design](/de/dokumentation/erste-schritte?role=design) oder in der [Entwicklung](/de/dokumentation/erste-schritte?role=development)
2. Lies die Dokumentation der Erweiterung im Marketingportal
3. Aktiviere die Figma-Bibliothek der Erweiterung zusätzlich zu Core Foundation und Core Components
4. Ergänze den Code der Erweiterung, sofern sie welchen mitbringt

</LearnAside>

</LearnBlock>

## Feedback gehört ins Repository der Erweiterung

Jede Erweiterung hat ein eigenes GitHub-Repository für Design-Feedback und Issues. Teile dort, was dir in deinem Bereich fehlt.

<LearnAside>

| Erweiterung          | Repository                                                                           |
| -------------------- | ------------------------------------------------------------------------------------ |
| Reisendeninformation | [extension-ri](https://github.com/db-ux-design-system/extension-ri/issues)           |
| DataViz              | [extension-dataviz](https://github.com/db-ux-design-system/extension-dataviz/issues) |
| Table                | [extension-table](https://github.com/db-ux-design-system/extension-table/issues)     |

Für Fragen zum Kern nutzt du die Kanäle, die unter [Wo du Hilfe bekommst](/de/dokumentation/lernen/ueber#wo-du-hilfe-bekommst) aufgeführt sind.

</LearnAside>

</LearnBlock>
