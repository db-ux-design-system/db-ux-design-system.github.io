## Beispielprojekte pro Framework

Jedes Projekt zeigt ein minimales, lauffähiges Setup für ein Framework. Das README jedes Projekts listet alle Schritte auf, mit denen es angelegt wurde – hilfreich, wenn du das Setup in deinem Projekt nachbauen willst.

| Framework          | Projekt                                                                                                      | Gebaut mit                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------ | ----------------------------- |
| React              | [react-example](https://github.com/db-ux-design-system/examples/tree/main/react-example)                     | Vite, Sass                    |
| React mit Tailwind | [react-tailwind-template](https://github.com/db-ux-design-system/examples/tree/main/react-tailwind-template) | Vite, Tailwind, Vite-Plugin   |
| Angular            | [angular-example](https://github.com/db-ux-design-system/examples/tree/main/angular-example)                 | Angular CLI, SCSS             |
| Vue                | [vue-example](https://github.com/db-ux-design-system/examples/tree/main/vue-example)                         | Vite, Sass                    |
| Python mit htmx    | [htmx-jinja-example](https://github.com/db-ux-design-system/examples/tree/main/python/htmx-jinja-example)    | Flask, Jinja2, Web Components |
| Eigenes Theme      | [custom-theme-example](https://github.com/db-ux-design-system/examples/tree/main/custom-theme-example)       | React, eigene Icon-Schrift    |

### Ein Beispiel lokal starten

```shell
git clone https://github.com/db-ux-design-system/examples.git
cd examples/react-example
npm install
npm run dev
```

Ersetze `react-example` durch den Ordner des Beispiels, das du starten willst. Das Python-Beispiel braucht zusätzlich `pip install -r requirements.txt` und startet mit `python app.py`.
