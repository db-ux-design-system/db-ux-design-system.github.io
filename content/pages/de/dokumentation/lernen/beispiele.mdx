Drei React-Demos laufen in **StackBlitz** ganz ohne lokales Setup. Der Editor öffnet sich in einem neuen Tab und startet die App.

## Kopiere nur das Beispiel, das du brauchst

**degit** kopiert einen einzelnen Ordner des Repositorys ohne Git-Historie. Ersetze `react-example` durch den Ordner deines Beispiels.

```shell
npx degit db-ux-design-system/examples/react-example my-app
cd my-app
npm install
npm run dev
```

<LearnAside>

### Alternativ das ganze Repository klonen

Wenn du alle Beispiele auf einmal willst, klone das Repository und wechsle in einen Ordner:

```shell
git clone https://github.com/db-ux-design-system/examples.git
cd examples/react-example
npm install
npm run dev
```

### Python-Beispiel

Das Python-Beispiel liegt in einem Unterordner: `db-ux-design-system/examples/python/htmx-jinja-example`. Statt der npm-Befehle braucht es `pip install -r requirements.txt` und startet mit `python app.py`.

</LearnAside>

## Aktualisiere, bevor du darauf aufbaust

Die Beispiele nutzen das **Whitelabel-Theme** und ältere Versionen. Aktualisiere sie und ergänze für ein Produkt das [DB Theme](/de/dokumentation/lernen/db-theme-einrichten 'Farben, Schriften und Icons der Marke.').

<LearnAside>

Ohne DB Theme zeigen die Beispiele die Whitelabel-Standardwerte statt der DB-Schrift und der DB-Icons.

So aktualisierst du die Pakete des Design Systems im React-Beispiel auf die neueste Version:

```shell
npm install @db-ux/react-core-components@latest @db-ux/core-components@latest @db-ux/core-foundations@latest
```

Nutze für andere Frameworks das passende Paket, zum Beispiel `@db-ux/ngx-core-components` oder `@db-ux/v-core-components`. Springst du dabei über eine Major-Version, prüfe die [Release Notes](/de/dokumentation/releases/release-notes) auf Breaking Changes.

</LearnAside>

</LearnBlock>

## Melde ein Beispiel, das nicht funktioniert

Eröffne ein Issue im [examples-Repository](https://github.com/db-ux-design-system/examples/issues 'Melde ein Problem mit einem der Beispielprojekte.'). Prüfe vorher, ob es das Issue schon gibt.

<LearnAside>

Probleme mit einer Komponente selbst, nicht mit dem Beispiel, gehören ins [core-web-Repository](https://github.com/db-ux-design-system/core-web/issues/new/choose).

</LearnAside>

</LearnBlock>
