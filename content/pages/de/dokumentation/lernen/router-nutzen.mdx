## Der Router-Link gehört in die Komponente

Komponenten mit Router-Unterstützung nehmen den **Router-Link deines Frameworks** als Inhalt auf. Die Komponente gestaltet den Link, dein Router übernimmt die Navigation.

<LearnAside>

| Komponente                                     | So nutzt du den Router-Link                                    |
| ---------------------------------------------- | -------------------------------------------------------------- |
| Navigation Item, Control Panel Navigation Item | Router-Link im Default-Slot                                    |
| Pagination                                     | Router-Link in jedem Pagination Item                           |
| Link (nur Angular)                             | Direktive `routerLink` direkt auf `db-link`                    |
| Button                                         | Nicht unterstützt – ein Link in einem Button ist nicht erlaubt |

Getestet sind die Standard-Router von Angular, React (React Router) und Vue (Vue Router). Andere Router funktionieren genauso, solange sie ein `<a>`-Element rendern.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Setze den Link in ein Navigation Item

Lege den Router-Link in den Default-Slot des **Navigation Items** oder des **Control Panel Navigation Items**.

```tsx
// React – NavLink aus react-router-dom setzt aria-current="page" am aktiven Link
<DBControlPanelNavigationItem>
	<NavLink to="/destination">Destination</NavLink>
</DBControlPanelNavigationItem>
```

<LearnAside>

### Angular

Importiere `RouterLink` und `RouterLinkActive` aus `@angular/router` in deiner Komponente. `ariaCurrentWhenActive` ist ein Input von `RouterLinkActive`, deshalb braucht der Link zusätzlich `routerLinkActive`.

```html
<db-control-panel-navigation-item>
	<a [routerLink]="link.path" routerLinkActive ariaCurrentWhenActive="page">{{ link.label }}</a>
</db-control-panel-navigation-item>
```

### Vue

`RouterLink` ist global verfügbar. Setze `ariaCurrentValue="page"`: Der aktive Zustand des Items folgt `aria-current="page"`.

```html
<DBControlPanelNavigationItem>
	<RouterLink :to="link.path" ariaCurrentValue="page">{{ link.label }}</RouterLink>
</DBControlPanelNavigationItem>
```

Dasselbe funktioniert mit `DBNavigationItem` bzw. `db-navigation-item`.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Markiere die aktuelle Seite mit aria-current

Die aktive Darstellung eines Navigation Items folgt `aria-current="page"` am Link. Der Router setzt das Attribut am Link der aktuellen Route, wie in den Beispielen oben.

<LearnAside>

Die Property `active` setzt nur `data-active`. Sie setzt kein `aria-current`, das Item wird dann nicht aktiv dargestellt und Screenreader sagen die aktuelle Seite nicht an. Nutze stattdessen den Router.

</LearnAside>

</LearnBlock>

## Nutze Router-Links in der Pagination

Übergib die Seiten selbst als **Pagination Items** mit einem Router-Link darin. Die Pagination setzt Seitenzahlen, `aria-current` und die Pfeil-Buttons für dich.

<LearnAside>

```tsx
const { page } = useParams();
const navigate = useNavigate();

return (
	<DBPagination currentPage={Number(page)} onPageChange={(next) => navigate(`/results/${next}`)}>
		<DBPaginationItem>
			<Link to="/results/1" aria-label="Seite 1 von 2">
				1
			</Link>
		</DBPaginationItem>
		<DBPaginationItem>
			<Link to="/results/2" aria-label="Seite 2 von 2">
				2
			</Link>
		</DBPaginationItem>
	</DBPagination>
);
```

Lass `totalCount` und `items` weg, wenn du die Items selbst übergibst. Kürzen und responsives Zusammenklappen gibt es in diesem Modus nicht, weil die Komponente nicht weiß, für welche Seiten deine Items stehen. Die Code-Beispiele für jedes Framework findest du im [Storybook](https://design-system.deutschebahn.com/core-web/version/latest/composition-storybook/).

</LearnAside>

</LearnBlock>

<LearnBlock>

## Nutze für Navigation einen Link statt eines Buttons

Ein Button kann keinen Router-Link enthalten. Führt eine Aktion auf eine andere Seite, nutze einen **Link** oder ein Navigation Item statt eines Buttons.

<LearnAside>

In Angular funktioniert die Direktive `routerLink` direkt auf der Link-Komponente:

```html
<db-link routerLink="/destination" variant="brand">Router-Link</db-link>
```

Importiere `RouterLink` zusammen mit `DBLink` in den `imports` deiner Komponente.

</LearnAside>

</LearnBlock>
