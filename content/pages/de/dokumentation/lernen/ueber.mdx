## Eine Basis für Design und Code

Das DB UX Design System ist die gemeinsame Basis für die digitalen Produkte der Deutschen Bahn. Design und Entwicklung nutzen dieselbe Foundation, dieselben Komponenten und dieselben Namen – in Figma und im Code.

Diese Dokumentation beschreibt Generation 3, die aktuelle Generation.

</LearnBlock>

<LearnBlock>

## Was es enthält

Die Foundation für die Tokens, Komponenten als Bausteine, Pattern, die sie kombinieren, Erweiterungen für besondere Bereiche und Themes, die die Marke anwenden. Die Komponenten gibt es als CSS, als Web Components und für Angular, React und Vue.

<LearnAside>

| Bestandteil   | Inhalt                                                                | Dokumentation                                            |
| ------------- | --------------------------------------------------------------------- | -------------------------------------------------------- |
| Foundation    | Tokens für Farben, Typografie, Abstände und Density                   | [Foundation](/de/dokumentation/foundation)               |
| Komponenten   | Bausteine für Interfaces in Design und Code                           | [Komponenten](/de/dokumentation/komponenten)             |
| Pattern       | Wiederkehrende Lösungen, die mehrere Komponenten kombinieren          | [Pattern](/de/dokumentation/pattern)                     |
| Erweiterungen | Bibliotheken für Bereiche wie Reisendeninformation oder DataViz       | [Erweiterungen](/de/dokumentation/erweiterungen)         |
| Themes        | Bringen eine Marke auf alles oben Genannte, zum Beispiel das DB Theme | [DB Theme](/de/dokumentation/ressourcen/pakete/db-theme) |

Native Komponenten für iOS und Android liegen in [eigenen Paketen](/de/dokumentation/ressourcen/pakete/native).

</LearnAside>

</LearnBlock>

## Jeder Inhalt hat einen Status

Ein Status zeigt dir, wie ausgereift eine Komponente, ein Pattern oder ein Template ist. **Stable** ist als UX-Standard verpflichtend, **Beta** wird empfohlen, **Concept** dient nur als Design-Referenz.

<LearnAside>

| Status     | Bedeutung                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| Concept    | Früher Ansatz, nichts ist final. Als Design-Referenz nutzbar – eine Implementierung im Code gibt es eventuell noch nicht. |
| Beta       | Funktionsfähig und weitgehend stabil. Kleinere Änderungen sind noch möglich. Teste gründlich und gib Feedback.            |
| Stable     | Ausgereift und verlässlich. **Verpflichtend** als UX-Standard.                                                            |
| Legacy     | Wird nicht mehr aktiv weiterentwickelt, nur noch kritische Fehlerbehebungen. Migriere auf aktuelle Inhalte.               |
| Deprecated | Wird in einem kommenden Major-Release entfernt. Plane den Ersatz ein.                                                     |

Releases folgen der semantischen Versionierung: Major-Releases werden vorab angekündigt, Minor- und Patch-Releases erscheinen laufend. Mehr dazu unter [Content Status](/de/dokumentation/releases/content-status) und [Versionierung](/de/dokumentation/releases/versionierung).

</LearnAside>

</LearnBlock>

<LearnBlock>

## Wie verbindlich es ist

Inhalte mit Status Stable sind der verpflichtende UX-Standard. Das DB Theme ist für alle Websites und Anwendungen der Deutschen Bahn erforderlich und darf außerhalb davon nicht verwendet werden.

<LearnAside>

Der Code des Design Systems steht unter der Apache-2.0-Lizenz. Das DB Theme und seine Assets sind die Ausnahme: Sie dürfen nur für Websites und Anwendungen der Deutschen Bahn verwendet werden.

</LearnAside>

## Wo du Hilfe bekommst

Du hast einen Fehler gefunden oder wünschst dir ein Feature? Eröffne ein Issue auf [GitHub](https://github.com/db-ux-design-system/core/issues/new/choose 'Fehler melden und Features wünschen.').
