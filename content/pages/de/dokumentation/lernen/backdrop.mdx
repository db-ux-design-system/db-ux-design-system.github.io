## Es gibt keine Backdrop-Komponente

Der **Drawer** bringt seinen Backdrop selbst mit. Für eigene Overlays setzt du dieselbe Farbe mit zwei Tokens: der stärksten Textfarbe und einer Transparenz.

<LearnAside>

Der Backdrop nutzt `--db-adaptive-on-bg-basic-emphasis-100-default` als Farbe und `--db-opacity-lg` als Transparenz. Beide passen sich an Light Mode und Dark Mode an.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Nutze die Tokens in CSS

Mische Farbe und Transparenz mit der relativen Farbsyntax, entweder an deinem eigenen Element oder an `::backdrop` eines Dialogs.

```css
.my-backdrop,
dialog::backdrop {
	background-color: color(
		from var(--db-adaptive-on-bg-basic-emphasis-100-default) srgb r g b / var(--db-opacity-lg)
	);
}
```

<LearnAside>

Für einen schwächeren Backdrop wie den Wert `weak` des Drawers nutzt du `--db-opacity-sm` statt `--db-opacity-lg`.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Nutze die Tokens in SCSS

Mit Sass nimmst du dieselben Tokens aus dem Foundation-Paket.

```scss
@use '@db-ux/core-foundations/build/styles/colors';
@use '@db-ux/core-foundations/build/styles/variables';

.my-backdrop,
dialog::backdrop {
	background-color: color(
		from #{colors.$db-adaptive-on-bg-basic-emphasis-100-default} srgb r g b /
			#{variables.$db-opacity-lg}
	);
}
```

<LearnAside>

Die schwächere Variante nutzt `variables.$db-opacity-sm`.

</LearnAside>

</LearnBlock>
