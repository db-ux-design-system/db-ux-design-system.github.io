## Eine Density legt die Lautstärke eines Bereichs fest

Es gibt drei **Densities**: `functional`, `regular` und `expressive`. Komponenten, Schriftgrößen und Abstände im Bereich ändern sich mit ihr.

<LearnAside>

| Density              | Einsatz                                          |
| -------------------- | ------------------------------------------------ |
| `functional`         | Fachanwendungen mit vielen Daten, große Tabellen |
| `regular` (Standard) | Anwendungen für Endkundinnen und Endkunden       |
| `expressive`         | Marketing-Seiten und Einzelseiten                |

Eine kleinere Density setzt auch Prioritäten: Eine Meta-Navigation in `functional` über einer Hauptnavigation in `regular` zieht weniger Aufmerksamkeit auf sich als die Hauptnavigation.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Setze die Density an einem Container

Setze `data-density` an ein beliebiges Element. Alles darin nutzt diese Density.

```tsx
<div data-density="functional">
	<DBButton>Speichern</DBButton>
	<DBInput label="Name" />
</div>
```

<LearnAside>

Die Klassen `db-density-functional`, `db-density-regular` und `db-density-expressive` funktionieren wie das Attribut.

</LearnAside>

</LearnBlock>

<LearnBlock>

## Ändere die Density der ganzen Seite

Setze das Attribut an `body`. Bereiche darin können trotzdem eine andere Density haben.

```html
<body data-density="functional">
	…
</body>
```

</LearnBlock>

<LearnBlock>

## Lade die Density-Klassen, wenn du nur die Foundation nutzt

Die Styles der Komponenten enthalten die Density-Klassen. Nutzt du die Foundation ohne die Komponenten, importierst du sie selbst.

```css
@import '@db-ux/core-foundations/build/styles/density/classes/all.css' layer(db-ux);
```

<LearnAside>

Ohne den Import gilt überall `regular`. Dein eigenes CSS folgt der Density, solange es die Tokens für Abstände, Größen und Schrift nutzt, weil sich ihre Werte mit der Density ändern.

</LearnAside>

</LearnBlock>
