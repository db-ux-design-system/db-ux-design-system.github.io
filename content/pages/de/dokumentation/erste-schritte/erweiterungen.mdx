## Kern oder Erweiterung?

Der Kern – Foundation und Komponenten – ist für jedes Produkt gleich. Erweiterungen bauen darauf auf und ergänzen Standards für einen bestimmten Bereich. Den Kern brauchst du immer. Eine Erweiterung brauchst du nur, wenn dein Produkt in ihrem Bereich arbeitet.

| Erweiterung          | Bereich                                           |
| -------------------- | ------------------------------------------------- |
| Reisendeninformation | Informationsstandards für Reisende                |
| DataViz              | Datenvisualisierung, derzeit in Beta              |
| Table                | Darstellung großer Datenmengen                    |
| Content              | einheitliche Kommunikation – noch nicht verfügbar |

Alle Erweiterungen stellt die Seite <DBLink href="/de/dokumentation/erweiterungen" variant="inline">Erweiterungen</DBLink> vor.

</DBSection>

## Mit einer Erweiterung starten

1. Richte zuerst den Kern ein – siehe [Design](/de/dokumentation/erste-schritte/design) oder [Entwicklung](/de/dokumentation/erste-schritte/entwicklung).
2. Lies die Dokumentation der Erweiterung im Marketingportal.
3. Aktiviere die Figma-Bibliothek der Erweiterung zusätzlich zu Core Foundation und Core Components.
4. Ergänze den Code der Erweiterung, sofern sie welchen mitbringt.

</DBSection>
