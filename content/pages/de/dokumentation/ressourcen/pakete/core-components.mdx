## Wann du dieses Paket nutzt

Nutze Core Components, wenn du HTML selbst schreibst – in einfachen Seiten, in einer Template-Engine oder in einem Framework, für das es kein eigenes Paket gibt. Du erhältst die Komponenten-Styles, aber keine Komponenten-Logik.

Wenn du mit React, Angular, Vue oder Custom Elements arbeitest, installiere stattdessen das passende Framework-Paket. Jedes davon enthält dieses Paket bereits.

<DBNotification variant="standalone" semantic="informational" headline="Foundation mitinstallieren">
	Dieses Paket hängt von `@db-ux/core-foundations` ab, und dein Stylesheet importiert beide. npm
	installiert die Foundation automatisch mit, pnpm stellt sie aber nur bereit, wenn du sie selbst
	angibst – deshalb installiert der Befehl unten beide.
</DBNotification>

</DBSection>

<DBSection spacing="small" width="auto">

## Bevor du anfängst

Du brauchst:

- Ein Projekt, in dem du das HTML selbst schreibst, zum Beispiel einfache Seiten oder eine Template-Engine.
- Node.js und einen Paketmanager. Die Befehle auf dieser Seite nutzen pnpm. Mit npm verwendest du `npm i` statt `pnpm add`.
- Einen unterstützten Browser: die letzten drei Versionen von Chrome und Edge, Firefox ESR und die letzten zwei Major-Versionen von Safari.

Für Produkte der Deutschen Bahn brauchst du zusätzlich Zugang zum Marketingportal für das [DB Theme](/de/dokumentation/ressourcen/pakete/db-theme). Du kannst ohne ihn starten: Das Whitelabel-Theme funktioniert sofort, das DB Theme ergänzt du später.

</DBSection>

<DBSection spacing="small" width="auto">

## Installation

```shell
pnpm add @db-ux/core-components @db-ux/core-foundations
```

</DBSection>

<DBSection spacing="small" width="auto">

## Styling-Setup

Ein Import deckt alles ab: alle Tokens der Foundation und die Styles aller Komponenten.

```css
/* index.css */
@layer whitelabel-theme, db-ux;

@import '@db-ux/core-foundations/build/styles/theme/rollup.css' layer(whitelabel-theme);
@import '@db-ux/core-components/build/styles/bundle.css' layer(db-ux);
```

### Asset-Pfad-Variante wählen

Die Theme-Datei gibt es in drei Varianten. Sie unterscheiden sich nur darin, wie sie die Pfade zu Icons und Schriften auflösen.

| Variante       | Asset-Pfad                        | Nutze sie, wenn                                                 |
| -------------- | --------------------------------- | --------------------------------------------------------------- |
| `rollup.css`   | `@db-ux/core-foundations/assets`  | dein Bundler Paketpfade auflöst                                 |
| `webpack.css`  | `~@db-ux/core-foundations/assets` | du mit Webpack baust                                            |
| `relative.css` | `../assets`                       | du Icons und Schriften in deinen eigenen public-Ordner kopierst |

## Erste Komponente

Schreibe das Markup wie auf der Komponentenseite dokumentiert und setze die Komponentenklasse.

```html
<button class="db-button" data-variant="brand">Artikel in den Warenkorb</button>
```

## Setup prüfen

Rendere einen Button mit Icon. Er zeigt an einer Stelle, ob Styles, Schrift und Icons laden.

```html
<button class="db-button" data-variant="brand" data-icon="arrow_right">
	Artikel in den Warenkorb
</button>
```

| Prüfpunkt | Erwartet                                                                                                                | Wenn nicht                                                                                                                                                              |
| --------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Styles    | Der Button hat einen gefüllten Hintergrund in der Markenfarbe und abgerundete Ecken.                                    | Der CSS-Import fehlt, oder das Theme wird nach den Komponenten-Styles geladen.                                                                                          |
| Schrift   | In den DevTools des Browsers ist die gerenderte Schrift des Buttons `OpenSans` – mit dem DB Theme `DB Neo Screen Sans`. | Der Browser findet die Schriftdateien nicht. Prüfe die Asset-Pfade aus dem Styling-Setup.                                                                               |
| Icon      | Vor dem Text erscheint ein Pfeil.                                                                                       | Der Browser findet die Icon-Schrift nicht. Im Netzwerk-Tab der DevTools schlägt eine Anfrage für eine `.woff2`-Datei fehl. Prüfe die Asset-Pfade aus dem Styling-Setup. |

</DBSection>

## Empfohlenes Tooling

Keines der beiden Pakete brauchst du für den Start. Ergänze sie, sobald deine erste Komponente erscheint.

### PostCSS-Plugin

Reduziert die Bundle-Größe, indem es `var()`, `calc()`, `color-mix()` und `light-dark()` zur Build-Zeit auflöst und ungenutzte Deklarationen entfernt.

```shell
pnpm add @db-ux/core-postcss-plugin --save-dev
```

### Stylelint-Plugin

Prüft dein eigenes CSS und SCSS gegen die Regeln des Design Systems, zum Beispiel ob du Tokens statt fester Werte referenzierst.

```shell
pnpm add @db-ux/core-stylelint --save-dev
```

</DBSection>

## Fehlerbehebung

| Symptom                                  | Ursache und Lösung                                                                                                                                                                                 |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Komponenten erscheinen ohne Styles       | Der CSS-Import fehlt, oder das Theme wird nach den Komponenten-Styles geladen. Prüfe, ob `@layer whitelabel-theme, db-ux;` die erste Anweisung in deinem Stylesheet ist.                           |
| Icons und Schriften werden nicht geladen | Die Asset-Pfad-Variante passt nicht zu deinem Setup. Wechsle zwischen `rollup.css`, `webpack.css` und `relative.css`.                                                                              |
| Tokens sind mit `pnpm` nicht definiert   | `pnpm` hebt transitive Abhängigkeiten nicht an. Installiere `@db-ux/core-foundations` explizit.                                                                                                    |
| CSS-Ausgabe ist mit Vite 8 fehlerhaft    | Vite 8 minifiziert mit LightningCSS und transformiert modernes CSS wie `light-dark()` falsch. Setze `build.cssMinify: 'esbuild'` in `vite.config.ts` und installiere `esbuild` als Dev-Dependency. |

Wenn das nicht hilft, öffne ein Issue im [core-web-Repository](https://github.com/db-ux-design-system/core-web/issues/new/choose). Prüfe vorher, ob es das Issue schon gibt.

</DBSection>
