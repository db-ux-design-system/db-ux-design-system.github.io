### Refactoring

Das folgende Refactoring erfordert besondere Aufmerksamkeit. Bestehende Instanzen müssen nach dem Update überprüft werden.

#### Heading

- **Alignment-Property entfernt:** Das Alignment ist keine Component Property mehr. Ein anderes Alignment als „Left“ stellst du direkt an der Ebene innerhalb der Komponente ein – an der „Heading“-Textebene (Default Heading) oder am „Container“-Auto-Layout (Custom Heading). Instanzen, die nicht linksbündig waren, sind nach dem Update nicht mehr korrekt verknüpft und müssen korrigiert werden (siehe <a href="/de/dokumentation/lernen/figma#alignment-einstellen">Figma Learn</a>).
- **Size-Property durch Visual Size ersetzt:** Die Property „Size“ wurde durch „Visual Size“ ersetzt. Die Visual Size setzt die visuelle Größe unabhängig von der semantischen Stufe. Instanzen mit einer der entfernten Größen sind nach dem Update nicht mehr korrekt verknüpft und müssen korrigiert werden.

Die bisherigen Size-Werte entsprechen folgenden Visual Sizes:

| Size  | Visual Size       |
| ----- | ----------------- |
| `3xl` | entfällt – nutze H1 |
| `2xl` | entfällt – nutze H1 |
| `xl`  | H1                |
| `lg`  | H2                |
| `md`  | H3                |
| `sm`  | H4                |
| `xs`  | H5                |
| `2xs` | H6                |
| `3xs` | entfällt – nutze H6 |

Textinhalte werden durch das Update nicht überschrieben.

#### Drawer

- **Children Slot ersetzt die Textebene des Drawer Headers:** Der Heading-Text des Drawer Headers liegt nun in einem Children Slot, konsistent zum Dialog Header und zur Entwicklung. Bestehende Heading-Inhalte werden nach dem Update zurückgesetzt und müssen in den Textlayer im Slot neu eingetragen werden.
