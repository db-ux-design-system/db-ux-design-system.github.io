### Refactoring

Das folgende Refactoring erfordert besondere Aufmerksamkeit. Bestehende Instanzen müssen nach dem Update überprüft werden.

#### Border Radius

Die Border-Radius-Tokens `3xs` bis `3xl` sind jetzt `0`. Komponenten aus dem Design System übernehmen diese Änderung automatisch. `border-radius-full` bleibt unverändert, damit runde Komponenten wie Badges oder Radios ihre Form behalten.

Wenn du `--db-border-radius-*`-Tokens in Custom Components verwendest, prüfe nach dem Update, ob sie dem neuen Markendesign entsprechen. Abgerundete Ecken bei Inputs, Buttons oder Containern sollen gemäß der Token-Änderung eckig werden. Komponenten, die `border-radius-full` für eine runde oder pillenförmige Form nutzen, dürfen bleiben wie sie sind.

#### Heading

- **Alignment-Property entfernt:** Das Alignment ist keine Component Property mehr. Ein anderes Alignment als „Left“ stellst du direkt an der Ebene innerhalb der Komponente ein – an der „Heading“-Textebene (Default Heading) oder am „Container“-Auto-Layout (Custom Heading). Instanzen, die nicht linksbündig waren, sind nach dem Update nicht mehr korrekt verknüpft und müssen korrigiert werden (siehe <a href="/de/dokumentation/lernen/figma#alignment-einstellen">Figma Learn</a>).
- **Size-Property durch Visual Size ersetzt:** Die Property „Size“ wurde durch „Visual Size“ ersetzt. Die Visual Size setzt die visuelle Größe unabhängig von der semantischen Stufe. Instanzen mit einer der entfernten Größen sind nach dem Update nicht mehr korrekt verknüpft und müssen korrigiert werden.

Die bisherigen Size-Werte entsprechen folgenden Visual Sizes:

| Size  | Visual Size       |
| ----- | ----------------- |
| `3xl` | entfällt – nutze H1 |
| `2xl` | entfällt – nutze H1 |
| `xl`  | H1                |
| `lg`  | H2                |
| `md`  | H3                |
| `sm`  | H4                |
| `xs`  | H5                |
| `2xs` | H6                |
| `3xs` | entfällt – nutze H6 |

Textinhalte werden durch das Update nicht überschrieben.

		'Setze die entsprechende Visual Size gemäß der Zuordnung oben.',
		'Setze für Instanzen mit 3xl oder 2xl die Visual Size H1 und für 3xs die Visual Size H6 – diese Größen wurden entfernt.',
	]}
/>

#### Drawer

- **Children Slot ersetzt die Textebene des Drawer Headers:** Der Heading-Text des Drawer Headers liegt nun in einem Children Slot, konsistent zum Dialog Header und zur Entwicklung. Bestehende Heading-Inhalte werden nach dem Update zurückgesetzt und müssen in den Textlayer im Slot neu eingetragen werden.

## Deprecations

### DB Theme Illustrative Icons

Die Library DB Theme Illustrative Icons ist deprecated und wird mit v7.0 entfernt. Das betrifft Design und Entwicklung. Bestehende Icons funktionieren bis zur Entfernung weiter, dieses Update erfordert also keine sofortige Nacharbeit. Verwende illustrative Icons nicht mehr in neuen Designs und Implementierungen und plane den Ersatz bestehender Verwendungen vor dem Update auf v7.0.

Es gibt keine Nachfolge-Library. Die DB Theme Icons sollen perspektivisch in größeren Größen bereitgestellt werden.
