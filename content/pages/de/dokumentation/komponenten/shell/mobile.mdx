### Navigationsstruktur

Auf Mobile trägt die Sub Navigation nur eine flache Ebene. Hat die Sub Navigation auf Desktop mehr als eine Ebene, wird die Navigation für Mobile umstrukturiert.

### Control Panel und Sub Navigation

Die folgende Tabelle zeigt, welche Kombinationen aus den Positionen des Control Panels und der Sub Navigation sowie den Varianten der Control Panel Navigation (Drawer) unterstützt werden.

| Control Panel | Control Panel Position | Control Panel Navigation (Drawer) | Sub Navigation Position |
| ------------- | ---------------------- | --------------------------------- | ----------------------- |
| Mobile        | Top                    | Drill Down                | ❌                      |
| Mobile        | Top                    | Drill Down                | Top (1 Level)           |
| Mobile        | Top                    | Drill Down                | Bottom (1 Level)        |
| Mobile        | Top                    | Tree                      | ❌                      |
| Mobile        | Top                    | Tree                      | Top (1 Level)           |
| Mobile        | Top                    | Tree                      | Bottom (1 Level)        |
| Mobile        | Bottom                 | Drill Down                | ❌                      |
| Mobile        | Bottom                 | Drill Down                | Top (1 Level)           |
| Mobile        | Bottom                 | Drill Down                | Bottom (1 Level)        |
| Mobile        | Bottom                 | Tree                      | ❌                      |
| Mobile        | Bottom                 | Tree                      | Top (1 Level)           |
| Mobile        | Bottom                 | Tree                      | Bottom (1 Level)        |
| Flat Icon     | Bottom                 | ❌                        | ❌                      |
| Flat Icon     | Bottom                 | ❌                        | Top (1 Level)           |

</DBSection>

### Unterschied zwischen Desktop und Mobile

Shell Mobile und Shell Desktop können unterschiedlich aufgebaut sein. Die Navigationsstruktur muss auf beiden Devices nicht identisch sein, sie kann je Device angepasst werden.
