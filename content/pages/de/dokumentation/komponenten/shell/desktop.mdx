### Control Panel Position

Die Anzahl der Navigation Items auf oberster Ebene entscheidet über die Position des Control Panels. Ab vier Items gibt Left ihnen eine dauerhafte vertikale Übersicht.

### Sub Navigation Position

Die Anzahl der Navigation Items auf Unterebene entscheidet über die Position der Sub Navigation. Ab sechs Items hält Left sie dauerhaft im Blick.

### Control Panel und Sub Navigation

Die folgende Tabelle zeigt, welche Kombinationen aus Positionen und Navigationsvarianten des Control Panels und der Sub Navigation unterstützt werden.

| Control Panel | Control Panel Position | Control Panel Navigation | Sub Navigation Position | Sub Navigation Variant |
| ------------- | ---------------------- | ------------------------ | ----------------------- | ---------------------- |
| Desktop       | Top                    | Popover                  | ❌                      | ❌                     |
| Desktop       | Top                    | Popover                  | Top                     | Popover                |
| Desktop       | Top                    | Popover                  | Left                    | Drill Down             |
| Desktop       | Top                    | Popover                  | Left                    | Tree                   |
| Desktop       | Left                   | Drill Down               | ❌                      | ❌                     |
| Desktop       | Left                   | Tree                     | ❌                      | ❌                     |
| Desktop       | Left                   | Drill Down               | Top                     | Popover                |
| Desktop       | Left                   | Tree                     | Top                     | Popover                |
| Flat Icon     | Left                   | ❌                       | ❌                      | ❌                     |
| Flat Icon     | Left                   | ❌                       | Top                     | Popover                |
