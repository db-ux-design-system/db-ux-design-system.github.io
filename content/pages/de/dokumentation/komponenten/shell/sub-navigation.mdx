## Richtlinien

<CollapsibleWrapper collapsedHeight="320px">

### Mobile Navigationstiefe

Auf Mobile trägt die Sub Navigation eine flache Ebene von Navigation Items. Navigation Item Groups können dort nicht eingesetzt werden.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"

		description="Verwende auf Mobile eine flache Ebene von Navigation Items."
	/>
	<GuidelineExample
		variant="dont"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4049-4&embed-host=share"
		description="Setze auf Mobile keine Navigation Item Groups ein. Sie können dort nicht verwendet werden."
	/>
</div>

### Anzahl auf Mobile

Die mobile Sub Navigation zeigt ihre Navigation Items in einer scrollbaren Zeile. Je mehr Items sie enthält, desto weniger davon sind gleichzeitig sichtbar.

<div className="guideline-examples">
	<GuidelineExample
		variant="do"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4093-8&embed-host=share"
		description="Setze in der mobilen Sub Navigation höchstens fünf Navigation Items ein."
	/>
	<GuidelineExample
		variant="caution"
		figmaUrl="https://embed.figma.com/design/RcpbbqfJwjNRlOwPhAX1im/Doku--Shell?node-id=4093-11&embed-host=share"
		description="Bei mehr als fünf Navigation Items geht beim Scrollen der Überblick verloren. Reduziere die Anzahl oder verteile die Ziele anders."
	/>
</div>

## Beispiele

<CollapsibleWrapper collapsedHeight="320px">

### Einklappbare Left-Navigation

Auf Desktop können Nutzer:innen Sub Navigation Left einklappen; initial ist sie immer ausgeklappt. Im eingeklappten Zustand bleibt nur der Button zum Ausklappen sichtbar.
